FreeLLM 使用教程

从查找资源到核对官方条件，用几步找到适合自己的 AI 工具与免费额度。

直接开始：跑通第一次免费 AI API 调用 →
01

选择资源类型

从主导航进入模型库、Skills、工具箱或工作流。模型库适合查找模型与 API；工具箱收录开发和创作工具；Skills 与工作流提供可复用的能力和流程。

浏览模型库 →查看 Skills →打开工具箱 →
02

筛选并比较条件

使用列表中的搜索和筛选缩小范围。留意免费额度、试用期限、地区要求、账号限制和最近核验时间；“免费”可能对应不同使用条件。

查看学生优惠 →查看最近更新 →
03

打开官方来源核对

每条资源都应以提供方的官网或官方文档为准。额度、价格、地区与资格要求可能变化；注册或接入前，请在官方页面确认当前条款。

FreeLLM 是信息索引，不提供第三方模型或 API 服务。详细边界请阅读免责声明。
04

收藏、提交或反馈

可以将感兴趣的资源加入收藏。发现失效链接、信息有误，或有新资源想推荐时，欢迎提交资源或通过邮件告诉我们。

查看我的收藏 →提交资源 →发送反馈邮件 →
