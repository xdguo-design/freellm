Evidence levels matter

End-to-end test
The workflow ran through a meaningful real task with observable output.
Artifact or task test
Specific behavior was exercised, but does not prove general reliability.
Partial or blocked
A capability was only partly confirmed, or external access prevented completion.

Practical review checklist

  1. Confirm the skill's task and required runtime tools.
  2. Inspect evaluation evidence and failure notes.
  3. Run it on disposable inputs before trusting production documents.
  4. Review generated artifacts and keep sensitive credentials out of prompts.
