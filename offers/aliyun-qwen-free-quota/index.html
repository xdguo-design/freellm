操作步骤Steps

  1. 确认免费额度

  2. 创建 API key

    在百炼控制台创建 API key，并只保存到本地环境变量 DASHSCOPE_API_KEY。

  3. 开启耗尽停止

    在控制台开启免费额度耗尽后的停止设置，避免测试请求意外进入付费计费。

    使用官方兼容 endpoint 和当前可用的 Qwen 模型 ID 发送短文本请求。
