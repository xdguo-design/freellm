LongCat API 调用

api

EndpointEndpoint
https://api.longcat.chat/openai/v1
认证Authentication
Authorization: Bearer API key

前置条件Prerequisites

  • 已注册 LongCat 平台LongCat
  • 已创建 API keyAPI key
  • 已确认账户可用额度与当前模型 IDID

操作步骤Steps

  1. 获取 API key

    从 LongCat 官方平台进入 API key 或开发者设置，创建密钥并保存为 LONGCAT_API_KEY 环境变量。

  2. 查看模型列表

    先访问官方模型接口，确认账户当前可见的模型 ID。

    可复制命令Copyable command
    curl https://api.longcat.chat/openai/v1/models -H 'Authorization: Bearer ${LONGCAT_API_KEY}'

    预期结果Expected：返回 HTTP 200 和 data 模型列表。

  3. 发送聊天请求

    把 model 改为模型列表中的真实 ID，先用短文本验证。

    可复制命令Copyable command
    curl https://api.longcat.chat/openai/v1/chat/completions -H 'Authorization: Bearer ${LONGCAT_API_KEY}' -H 'Content-Type: application/json' --data '{"model":"LongCat-Flash-Chat","messages":[{"role":"user","content":"Hello"}]}'

    预期结果Expected：响应包含 choices[0].message.content。

验证动作Validation

GET /openai/v1/models 返回 HTTP 200，随后聊天接口返回 choices；额度和模型可用性以控制台为准。
