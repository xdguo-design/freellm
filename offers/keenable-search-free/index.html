Keenable publishes a monthly free request allowance and a simple per-request price after the free allowance.

如何使用

使用 Keenable Search 或 Fetch 获取网页结果

前置条件

  • Keenable 账号或 keyless 公共入口
  • 可选 KEENABLE_API_KEY

步骤

  • 打开官方 CLI 文档并安装 keenable-cli
  • 设置可选 API Key 或使用 keyless 入口
  • 执行 Search 或 Fetch 并设置消费上限

shell

keenable search 'latest AI news' --api-key ${KEENABLE_API_KEY}

Official pricing lists 100K free requests per month and $4 per 1,000 requests; official CLI docs show Search and Fetch usage.
