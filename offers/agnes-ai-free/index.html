如何使用

通过 Agnes AI 的 OpenAI 兼容 API 调用文本、图片和视频模型；免费/default 层受速率限制

前置条件

  • Agnes AI account
  • Agnes AI API key

步骤

  • Create an Agnes AI account and API key in the official console
  • Send a request to the OpenAI-compatible endpoint with one of the listed model IDs
  • Check the official model catalog for current rate limits and image/video request formats

curl

curl https://apihub.agnes-ai.com/v1/chat/completions --header 'Authorization: Bearer ${AGNES_API_KEY}' --header 'Content-Type: application/json' --data '{"model":"agnes-2.5-flash","messages":[{"role":"user","content":"Hello"}]}'
