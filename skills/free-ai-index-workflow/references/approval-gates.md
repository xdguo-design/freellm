# 确认与发布门控

## Gate A：设计

- [ ] 目标、非目标、输入输出和测试行为已写清楚。
- [ ] 用户已确认设计或明确要求按既有设计执行。

## Gate B：官方发布资格

- [ ] 价格/额度/有效期/地区/注册条件有当前官方来源。
- [ ] 同行仓库和社区评论没有被当成官方证据。
- [ ] candidate 已被人工确认，状态可以从 `needs_review` 进入公开状态。

## Gate C：视觉改版

- [ ] 已生成至少三个可运行原型。
- [ ] 用户明确选择了方向。
- [ ] 正式页面的内容、组件和数据映射已说明。

## Gate D：部署

- [ ] 全量测试通过，允许的浏览器跳过有明确原因。
- [ ] `python scripts/build_static.py --check` 通过。
- [ ] 已确认正确的项目、域名、分支和部署范围。
- [ ] 不把 `data/candidates.json`、社区快照或未审核内容当成公开 offer。

任何 Gate 未满足时，输出阻塞原因和下一步，不自行越过门控。
