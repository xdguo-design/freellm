# 发布前人工核验清单

- [ ] 来源仍是官方页面，且页面没有跳转到不明域名。
- [ ] 产品类型没有把免费 IDE 写成免费 API。
- [ ] 免费机制明确区分永久、周期额度、试用、首月促销和开放权重。
- [ ] 额度单位正确：credits、tokens、requests、hours 不能混写。
- [ ] 有效期、活动截止时间和续费价格已分别记录。
- [ ] 手机号、银行卡、账号地区和 Endpoint 地区没有猜测。
- [ ] 直接注册、下载或模型卡地址可打开。
- [ ] 证据摘要能直接支持当前结论。
- [ ] 变更不会覆盖人工已确认的信息。
- [ ] 公开页面没有出现 API Key、用户隐私或账户余额。
