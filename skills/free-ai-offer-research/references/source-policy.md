# 来源与访问策略

## 允许来源

| 来源 | 允许用途 | 证据强度 |
|---|---|---|
| 官方价格页 | 价格、免费层、续费、额度 | 高 |
| 官方产品页 / FAQ | 产品范围、注册条件、地区限制 | 高 |
| 官方 API 文档 | Endpoint、兼容性、调用限制 | 高 |
| 官方 GitHub / Hugging Face / ModelScope | 开放权重、许可证、下载方式 | 高 |
| 官方公告 | 限时促销、首月价格、活动期限 | 高 |
| 博客、论坛、搜索摘要 | 发现线索，不可作为唯一发布证据 | 低 |

## 请求约束

- 仅 HTTPS；拒绝 URL 中的用户名、密码和 token。
- 使用低频请求、固定 User-Agent、超时和响应体大小限制。
- 遵守 robots.txt、服务条款和公开访问边界。
- 不登录、不提交注册、支付或试用表单。
- 不处理验证码、不绕过地区封锁、不轮换代理规避限制。
- 单次失败记录为来源失败；至少经过再次检查和人工确认才判断过期。

## 证据规则

关键结论至少保存一个官方 URL 和一句短证据摘要。不能从页面明确读出的字段写 `unknown`，不能用推测填充手机号、银行卡、商用许可或续费规则。
