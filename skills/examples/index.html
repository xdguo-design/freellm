Skill 实测例子

每个 Skill 配一个它本应处理的真实任务：把 SKILL.md 全文作为 system prompt，交给免费模型完成，再按预设检查项判定是否达成。下面是真实输出摘录，失败的调用照实标注“调用失败”，不计分、不补造。

测试时间：— · 运行位置：— · 模型：—

全部调用：通过 0 · 部分通过 0 · 未通过 0 · 调用失败 0

  • 0通过 个 Skill
  • 0部分通过 个 Skill
  • 0未通过 个 Skill
  • 0调用失败 个 Skill
how to read

怎么看这些结果

  • 通过：所有检查项都满足；部分通过：满足 ≥60%；未通过：低于 60%；调用失败：接口报错、超时、空输出或本轮未执行，没有可评分的输出。
  • 这是任务级测试：模型不能运行 Skill 自带的脚本 / CLI，只看它能否按 Skill 的说明给出正确的步骤、代码或文档，不等同原仓库端到端。
  • 耗时是从发出请求到流式输出结束的总时间，括号内为首个 token 时间；思考型模型的推理时间包含在内。
