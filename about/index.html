关于 FreeLLMAbout FreeLLM

FreeLLM（freellm.top）整理免费模型、免费额度、免费 IDE、API、开放权重和相关工具。每个条目都记录平台、限制条件、地区、注册要求和官方入口——不吹"全都免费"，只写有证据的结论。FreeLLM (freellm.top) is a curated directory of free models, free tiers, free coding IDEs, APIs, open-weight models and related tools. Every entry records the platform, limits, region restrictions, sign-up requirements and the official link — no "everything is free" hype, only evidence-backed conclusions.

01 / why

为什么做这个站Why this site exists

AI 工具的"免费"很少是简单的一句话：免费额度有速率限制、学生优惠要教育认证、开放权重不等于免费推理、限时公测随时会结束。信息散落在各厂商的定价页、文档和公告里，而且经常变化。FreeLLM 把这些条件逐条整理、标注来源和核验日期，帮你在动手注册之前先看清楚限制。"Free" in AI tooling is rarely one sentence: free quotas have rate limits, student offers need education verification, open weights don't mean free inference, and public betas can end at any time. The details live across vendor pricing pages, docs and announcements — and they change often. FreeLLM records these conditions entry by entry, with sources and verification dates, so you can see the limits before you sign up.

02 / method

收录方法Methodology

  • 只用官方来源：每条记录都带官方定价页、文档或公告链接，可点开复核。Official sources only: every entry links to the vendor's pricing page, docs or announcement so you can verify it yourself.
  • 按机制区分免费：免费额度、试用、促销、学生资格、开放权重和低成本路径分开标注，不混成一个"免费"标签。Free status separated by mechanism: recurring quota, trials, promotions, student eligibility, open weights and low-cost paths are labeled separately instead of one generic "free" tag.
  • 标注核验日期：每个条目记录最近核验时间；未核验的结论如实标记，不冒充已确认。Verification dates: each entry carries its last-checked date; unverified conclusions are labeled as unverified, never presented as confirmed.
  • 不伪造评分：外部信号（GitHub Stars、Hugging Face Likes 等）按原始公开数据展示，不合并成单一分数。No fabricated scores: external signals (GitHub stars, Hugging Face likes) are shown as raw public data, not merged into a single score.
03 / updates

更新机制How it stays current

本站每天自动运行公开来源检查，产出候选发现和下线记录；所有新增条目都经过人工审核后才会进入正式目录。每日变更日志公开记录新增、恢复和下线情况，模型目录同步时按 new / current / stale 标记数据新鲜度。项目源码开源于 GitHub。The site runs automated checks against public sources daily, producing discovery candidates and retirement records; new entries enter the directory only after human review. The daily change log records additions, restorations and removals, and the model catalog is synced with new / current / stale freshness markers. The source code is public on GitHub.
