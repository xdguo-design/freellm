03 / TRUST LAYER

我们怎么判断一个公益站？

01

真实免费条件

免费模型、赠额、每日签到、邀请奖励、充值返利分开写。需充值才能领取的不标成无门槛公益。

02

模型与来源

只对有可靠依据的模型名称做确定性陈述；第三方自称「官方同款」不代表经过身份验证。

03

可用性与隐私

访问成功、登录成功、真正完成 API 调用属于不同证据层级。第三方站点勿提交密钥、隐私数据或生产代码。

状态说明：官方规则只表示从官方页面获取对应信息；第三方导航仅用于发现线索。当前未对本页所有入口执行自动化 API 调用验证。
