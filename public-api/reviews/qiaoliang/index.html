02 / FACT CHECK

资料证实了什么？

  • 主页自称收录公益、免费和付费 API。
  • 页面提供「公益」「付费」「检测站」类别入口。

03 / OPEN QUESTIONS

我们还不知道什么？

  • 具体收录站点及其是否经过人工审核。
  • 各站免费配额、隐私规则、模型 ID 与实际可用性。
  • 检测站数值的测试方法、频率、节点和失败样本。

04 / PRACTICAL STEPS

建议怎样验证？

  1. 将当前站点视作候选发现索引，不直接引用其评分。
  2. 逐项核对注册门槛、优惠条件和官方文档。
  3. 没有可验证的单站说明时不推荐到正式主目录。
