GATEWAY / FROM DIRECTORY TO API

它的「导航」与「自营 API 网关」是两回事

导航域名 link.hcnsec.cn 主要用于发现其他站点；api.hcnsec.cn 是同一运营方对外提供的中转 API。后者的说明只能算站方自述，不能用来证明被导航收录的其他站点安全稳定。

文档 Base URLhttps://api.hcnsec.cn/v1
实际请求路径/v1/chat/completions
文档示例模型别名DeepSeek-V4-Pro
文档密钥流程控制台「密钥」→ 创建令牌 → 默认 auto 分组

出现调用错误时，先查这几项

  1. 确认在自营网关创建的是 sk- 令牌，客户端提供正确的 Bearer 头；不要将真实密钥发给任何导航或评价网站。
  2. 检查客户端是否重复追加 /v1 或拼错 /chat/completions。
  3. 检查请求中的模型别名是否存在于该网关当前模型列表，而不是照抄其他平台的模型 ID。
  4. 如果返回 401，先看令牌；403 优先核对免费 / svip 分组权限；429 可能触发令牌或全站流控，具体以返回体为准。
  5. 即使文档宣称「1300+ 上游」或「不存储对话用于训练」，也不能据此认定其上游真实性、个人数据处理措施已经经过独立审计。

来源：站方 curl 文档 ↗ · 站方 FAQ ↗。以上是排查路线，不代表 FreeLLM 已取得账号、持密钥成功调用或验证网关隐私承诺。

03 / OPEN QUESTIONS

我们还不知道什么？

  • 每个被收录中转站的实际可用率和上游模型真实性。
  • 导航的评论审核、赞助标识与商业利益披露完整性。
  • 每家中转是否记录请求内容、如何删除数据、资金与跑路风险。

04 / PRACTICAL STEPS

建议怎样验证？

  1. 只把导航当发现工具，进入候选站点后重新找其正式使用规则。
  2. 注册前记录赠额是否必须实名、充值、邀请或签到；切勿混淆平台虚拟币与美元。
  3. 先使用无隐私内容的测试提示词，获得明确授权后才可实测；生产环境不得直接使用未经审计的中转。
