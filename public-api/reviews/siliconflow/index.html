01 / EDITORIAL VIEW

为什么给这个分数？

平台身份和接入入口可确认；免费额度证据、注册门槛及隐私配置的公开透明度尚待提升。

公式：证据×7 + 免费条款×6 + 接入门槛×4 + 隐私控制×3。维度以公开可读资料为依据；低分不意味着已证实存在安全问题。

02 / FACT CHECK

资料证实了什么？

  • 官方控制台入口会重定向到 SiliconFlow 账号登录页。
  • 官方登录页列出手机验证与其他登录入口。

03 / OPEN QUESTIONS

我们还不知道什么？

  • 当前注册赠额、模型免费标识与额度重置时间。
  • 是否强制实名认证、是否限制地区或必须绑卡。
  • 实际速率、调用成本及支持模型保真。

04 / PRACTICAL STEPS

建议怎样验证？

  1. 进入官方控制台或官方价格文档核对模型级费用。
  2. 先确认手机号/实名认证及额度到期条件，不通过第三方邀请码判断福利。
  3. 完成最小非敏感请求实测之前，保留『资料待核验』标签。
