01 / EDITORIAL VIEW

为什么给这个分数？

官方文档完整、免费入口明确、兼容 API 接入方便；主要扣分来自日限额、免费模型更替和各上游数据策略差异。

公式：证据×7 + 免费条款×6 + 接入门槛×4 + 隐私控制×3。维度以公开可读资料为依据；低分不意味着已证实存在安全问题。

02 / FACT CHECK

资料证实了什么？

  • 官方定价页显示 Free 方案 50 requests/day。
  • 官方免费模型集合展示可选 free 模型与定价信息。
  • 部分免费模型页明确提示训练数据政策可能不同。

03 / OPEN QUESTIONS

我们还不知道什么？

  • 具体地区访问和单个免费模型当前容量。
  • 高峰期成功率、延迟与真实 token 用量。
  • 使用某个模型时上游如何处理数据，需按该模型核实。

04 / PRACTICAL STEPS

建议怎样验证？

  1. 在官方 Free Models 集合中选标注免费的模型。
  2. 按官方价格页核对账户级每日请求限额，而非假设每个模型独立计数。
  3. 核对模型页的数据使用政策，采用非敏感请求做最小测试。
