QUICK START / 安全接入

从注册到第一条成功响应

  1. 在 控制台 ↗ 注册，进入密钥页创建 API Key，核对 auto 分组。
  2. 确认当前模型广场标明免费层的模型别名，不要把 svip 模型误认作免费。
  3. 把令牌仅保存在自己的本地环境变量，使用最小无敏感内容请求。
  4. HTTP 200 且 JSON 包含 choices 的有效回复，才算一次调用成功；不要仅凭网页能够打开就认定 API 可用。

Python 最小调用示例

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["HCNSEC_API_KEY"],
    base_url="https://api.hcnsec.cn/v1",
)
result = client.chat.completions.create(
    model="DeepSeek-V4-Pro",
    messages=[{"role": "user", "content": "只回复 OK"}],
    max_tokens=8,
)
print(result.choices[0].message.content)

先安装 pip install openai 并在本地设置 HCNSEC_API_KEY。示例模型为运营方文档别名，须以个人控制台当前可调用列表为准。本站不要求你上传密钥。

为什么不是稳定性五星？

这次用户已经确认好用，是一条积极且有用的真实体验。要升级到可量化成功率，我们还需要跨时段的可复现请求记录，并记录 401/403/429、超时、余额扣减等信息。

03 / OPEN QUESTIONS

我们还不知道什么？

  • 不同日期、不同地区的请求成功率与 P50/P95 延迟。
  • 实际扣费、赠额数量、签到规则与免费模型的实时变化。
  • 网关所标示模型别名对应的真实上游实现和模型版本。
  • 上游处理链、敏感文本保留政策及是否有第三方审计。

04 / PRACTICAL STEPS

建议怎样验证？

  1. 仅使用官网控制台注册，在密钥页创建令牌，确认分组和余额；不要把密钥交给 FreeLLM。
  2. 在平台当前模型列表中选免费层模型，将 Base URL 配置为 https://api.hcnsec.cn/v1。
  3. 以无敏感信息的最小对话请求测试，再观察状态码、响应耗时、模型 ID 与余额变化。
  4. 如 401 核对令牌，403 核对模型和分组，429 核对限流；具体以网关响应为准。
