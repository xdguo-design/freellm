FreeLLM 如何核验免费 AI 资源

我们不销售模型，也不替任何平台背书。目录里的「免费」必须能对应到可核对的机制：官方文档、价格页、活动规则或可复现的实测记录。本文说明核验标准、证据分级与使用前自查清单。

关于 FreeLLM →AI 实用观察 →实测榜 →

1. 我们在核验什么

FreeLLM 收录的是「可公开使用的免费或限免 AI 能力」：网页工具、API 额度、开放权重模型、限时活动等。核验目标不是证明某产品永远免费，而是在某个时间点说明：免费机制是什么、边界在哪里、证据来自哪里。

  • 可访问性：公开入口是否仍可打开，是否需要付费墙或地区限制。
  • 免费机制：免费层、新人额度、活动期限、速率限制是否写清楚。
  • 可复核性：关键结论能否对应到官方页面、changelog 或可复现测试。

2. 证据分级

  1. 一级（优先）：厂商官方文档、定价页、产品更新公告、GitHub README/Release。
  2. 二级：官方博客、可核对的产品内界面截图（注明日期与账号类型）。
  3. 三级（仅作线索）：第三方汇总、社群截图；不会单独作为「已确认免费」的依据。

若只有三级线索，我们会标注「待核验」或暂缓收录，而不是写成确定结论。

3. 「已实测」如何标注

只有在我们用自有账号完成最小可复现步骤后，才会标记「已实测」：

  • 注册/登录路径可走通；
  • 至少完成一次目标能力调用（例如一次对话、一次 API 请求）；
  • 记录日期、模型/产品 ID、平台与可见限制（RPM、日额度等）。

没有完成上述步骤的条目，最多写「来源已核对」，不会冒充实测。

4. 评分与榜单

公开评分必须绑定：测试集或任务说明、模型/产品精确 ID、平台、日期与原始结果摘要。宣传分、模糊「体验很好」不会进入实测榜。

5. 使用前自查清单（给读者）

  1. 打开官方定价/文档，确认免费档是否仍存在。
  2. 核对地区、账号类型、模型白名单与速率限制。
  3. 用自己的账号发最小请求，观察鉴权与计费行为。
  4. 不要把「限时活动」理解成「永久免费」；活动结束后以官方最新说明为准。
  5. 向未知条款的端点提交密钥或保密代码前，先读隐私与数据条款。

6. 错误与更新

免费政策变化很快。若你发现目录与官方不一致，欢迎通过 提交资源 告知；我们会按证据分级更新或下架，并在日志中保留变更痕迹。
