FreeLLM 如何核验免费 AI 资源

免费额度、试用与「限时活动」变化很快。本页公开我们收录与核验时使用的标准，方便你判断一条记录能信到什么程度，以及在使用前应自己再确认什么。

FreeLLM 不是模型厂商，也不替任何服务商背书。我们做的是信息整理与条件核验：尽量把「官方说了什么」「我们什么时候看过」「有没有真实调用过」分开写清楚。下面说明具体怎么做。

1. 为什么需要独立核验

免费 AI 资源常见三类问题：

  • 过期仍被传播：社区帖、旧榜单和截图里的「永久免费」可能已经改成限时或需绑卡。
  • 条件被简化：「免费 API」可能只对特定地区、特定模型或新用户有效，且有 RPM / 日额度上限。
  • 演示 ≠ 产品承诺：企业发布会、Agent 演示和评测分数，不能直接等同于个人账号的免费资格。

因此我们把每条记录拆成：来源链接、免费机制类型、额度与限制、地区/账号要求、最近核验日期。缺少官方依据的条目不会标记为「已验证」。

2. 官方来源优先

收录时优先采信以下来源（按可信度大致从高到低）：

  1. 厂商定价页、文档、控制台说明中的免费额度段落
  2. 厂商官方博客或公告中明确写明的试用 / 免费计划
  3. 可公开访问的 API 文档中的 rate limit 与 pricing 表
  4. GitHub 官方仓库 README 中与免费配额直接相关的说明（需与官网交叉核对）

二手汇总站、未注明出处的截图、仅出现在社群转发里的「内部名额」，默认不作为单独收录依据。若你提交资源，请尽量附上可点击的官方 URL。

3. 免费机制如何标注

我们不会把所有「能白嫖一下」的东西都写成「永久免费」。常见标签包括：

  • 长期免费 / Ongoing free tier：官方写明持续提供的免费额度或免费档，但仍可能改规则。
  • 试用 / Trial：有明确期限或一次性额度。
  • 限时活动 / Promo：活动页或公告有起止时间；过期后应变更为已结束或下线。
  • 学生 / 教育优惠：需要学生认证或教育邮箱，资格以官方审核为准。
  • 开源权重可下载：模型权重本身可下载，不等于推理、托管或 API 调用免费。

「模型免费」与「调用免费」必须分开看：本地跑开源模型仍有硬件与电费成本；第三方网关的免费层往往有模型子集、速率与地区限制。

4. 证据分级：写了什么 vs 测过什么

目录里的状态大致分三层：

状态 含义 你应该怎么用
官网已验证 我们核对过官方页面上的免费条件与入口，并记录核验日期。 适合作为「去哪看规则」的起点；注册前仍应打开官方页确认。
已实测 / 接口已验证 在标注的环境与日期下，实际完成过调用或可用性检查。 说明「当时能通」，不保证你现在的账号与地区仍然一样。
待复核 / 来源异常 官方页打不开、条件表述冲突，或距上次核验已过久。 请以官方最新说明为准，或通过联系页反馈。

完整评测（例如 免费大模型 API 实测榜）只会在真实调用同一套固定题目后发布分数，并保留测试日期、运行环境与原始结果结构。没有跑过的模型不会凭宣传材料给分。

5. 实测流程（以文本 API 为例）

当前公开的文本评测套件大致遵循：

  1. 固定题集：同一组题目覆盖中文知识、推理、代码、指令格式、长文本、工具调用与防幻觉等维度。
  2. 统一参数：如 temperature、max tokens 等保持一致，便于横向比较。
  3. 可自动判定的题：代码题尽量实际跑测试；工具调用检查函数名与参数；防幻觉题检查是否拒绝编造。
  4. 延迟与速度：记录首 token 延迟与生成速度，作为体验参考，不单独等同于「更聪明」。
  5. 公开方法：方法说明与维度定义写在评测页；排名会随新一轮运行更新。

注意：评测环境（例如托管运行器所在地区）可能与你本机不同，跨区延迟与可用性会有差异。分数用于比较「同一天、同一套题」下的相对表现，不是终身质量证书。

6. 每日发现与变更日志

每日发现记录我们扫描到的新增、恢复、下线与来源异常。原则是：

  • 同一资源首次出现的日期计入「新发现」，避免同一条反复刷「新增」。
  • 下线或额度变更以可核查的官方信号或复测失败为依据，并在日志中保留痕迹。
  • 没有当天扫描结果时，不会伪造「今日已扫完」的数据。

7. 你在使用前应自己复核的清单

即使条目显示「官网已验证」或「已实测」，在依赖它做生产或课程作业前，建议快速过一遍：

  1. 打开官方定价 / 文档页，确认免费档是否仍存在。
  2. 核对地区、手机号、实名或学生认证要求。
  3. 看清 RPM、日请求数、token 上限，以及是否仅限部分模型。
  4. 用你自己的账号发一条最小请求，确认鉴权与计费行为。
  5. 把 API Key 等凭证只放在本地或密钥管理服务，不要发到公共仓库或邮件。

8. 我们不会做的事

  • 不会为付费排名或广告客户单独抬高目录排序权重（排序因子在 关于页 公开）。
  • 不会把未跑过的模型标成「已实测」。
  • 不会收集你的 API Key；联系邮箱仅用于纠错与合作沟通。
  • 不会保证任何第三方服务持续免费或零故障。

9. 如何反馈错误

发现过期活动、404、额度变化或重复条目时，请通过 联系页 或公开邮箱反馈，并尽量附上：

  • FreeLLM 上的条目链接
  • 对应的官方页面 URL
  • 你看到异常的大致日期与截图/原文要点（勿发送密钥）

我们会根据可核查来源修订记录，并在更新日志中保留必要痕迹。
