Kilo Code 免费 AI 编程怎么用？Auto Model 路由与 3 个值得实测的新模型

Kilo Code Auto Model Free 实操指南：动态免费模型路由、模型候选选择、隐私风险与可复核的编程 Agent 测试方法。

核验摘要
  • 官方已确认：Auto Model 有 Free、Efficient 与 Frontier 等不同档位；Free 会在当前可用免费模型中路由，具体底层模型会变化。
  • 近期值得实测：Kilo 在 10 月 10 日的官方博客推荐关注 Step 5 Preview、Claude Haiku 5.5 与 Glyph Cluster，分别可按多步骤工作、轻量重复任务、代码审查/调试方向测试。
  • 不要混淆：博客推荐不等于三个模型都免费。应以当前模型选择器显示为准。

Kilo Code 的 Auto Model Free 能在当前可用的免费模型之间自动路由，适合想快速试用 AI 编程代理、但又不想先承担 API 费用的开发者。关键是理解它提供的是动态路由，而不是某个固定模型永久免费。

建议怎么开始

  1. 安装官方 IDE 扩展或 CLI，并确认版本满足 Auto Model 自动切换要求。
  2. 选择 kilo-auto/free，先拿一个不含敏感数据的小仓库验证。
  3. 让模型先只读梳理目录、入口和测试命令，确认计划后再授权它改一个小问题。
  4. 记录成功率、首 Token 延迟、上游限速、人工返工时间和每次成功任务成本。

三个模型方向怎么分工

Step 5 Preview：适合读多文件、规划多步骤任务和结合多模态资料的测试。Claude Haiku 5.5：可重点测试摘要、分类、提取、路由等重复性小任务。Glyph Cluster：可拿来测试代码审查、调试与迁移规划，但模型的可用状态、输入能力和隐私条款要单独确认。

免费模式最容易忽略的两个坑

第一，代理对话、IDE 自动补全和后台任务可能使用不同模型配置。若目标是全流程控制成本，要逐项确认设置，不能只切换聊天模型。第二，免费路由可能连接会记录提示词/输出的上游端点。不要向未知数据处理条款的免费端点提交密钥、客户数据或保密代码。
