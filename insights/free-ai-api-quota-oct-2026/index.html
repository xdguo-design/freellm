01 / AMD Radeon Cloud：不启 GPU 实例的共享免费端点

AMD 的 Public Free Model APIs 是免费的共享模型服务。开发者登录 Token Factory，在模型列表选择可用端点，详情弹窗给出 Base URL、模型 ID、密钥及请求示例。模型名单由平台调整，不宜把某一天看到的十款模型写成永久固定。当前账号真正可用的模型应通过控制台或 GET /v1/models 核对。

  1. 打开 AMD Token Factory 并登录。
  2. 查看 Public Free Model APIs，选择要测的模型并按页面指引获取 API Key。
  3. 先用无敏感内容的小请求验证，再记录模型 ID、返回状态与限流。
curl https://developer.amd.com.cn/radeon/api/v1/models \
  -H "Authorization: Bearer $RADEON_API_KEY"
不能忽略的条款：AMD 明确把免费接口定位为实验、学习和 Demo，禁止生产业务依赖；不允许通过代理、API 网关或其他方式转供第三方，也没有服务 SLA。不要在免费试验端点提交私有代码、密钥、客户数据。

02 / Z.ai：GLM-4.7-Flash 与 GLM-4.6V-Flash 的 Free 价格

截至核对日，Z.ai 官方定价表 对 GLM-4.7-Flash 和 GLM-4.6V-Flash 两款模型，列出的输入、缓存输入、缓存存储及输出均为 Free。前者可用于文本处理和对话原型，后者可在图片理解方向做试验。

这里的“免费”严格指这些计费项目的价格标签，不应自动推导无限并发、无条件商用或相关工具服务全部免费。跨地区和跨平台核价时，更不能把同一家模型厂商的不同 API 站点混为一个价格口径。

03 / 腾讯 TokenHub：新人体验包比“旧混元百万 Tokens”更值得先看

腾讯官方已说明原混元平台相关功能逐步迁移至 TokenHub。目前 TokenHub 的 新人免费体验包文档 写明：语言模型及多模态理解模型提供 每模型 100 万 Tokens 体验额度，通常自领取起一年有效，每主账号每模型限领一次。该期活动文档标注至 2026-12-31，实际能否领取以控制台为准。

  1. 注册腾讯云账号并完成实名认证。
  2. 进入 TokenHub 控制台的模型广场，打开“新用户福利免费体验”。
  3. 只勾选近期需要的模型；部分支持的模型也会在首次调用时自动领取。
  4. 创建对应地域 API Key，再按当地接口地址调用；广州和新加坡接入地址不可跨地域混用。

旧版腾讯混元计费文档另有“若干模型共享 100 万 Tokens，Embedding 单独 100 万”的一次性包规则。这是另一套产品和规则，不能与 TokenHub 新人包相加计算。TokenHub 免费额度耗尽且未开启后付费时，按官方说明服务会停止。

04 / GLM-5.3-Flash：历史五折不等于今天仍在五折

互联网流传的人民币活动报价为每百万 Tokens 输入 0.4 元、缓存命中 0.115 元、输出 1.4 元，标准报价则分别为 0.8、0.23、2.8 元。但此前的人民币五折信息没有得到 2026 年 10 月 14 日的官方账号价确认，因此不能直接标为“这周仍有效”。

可独立核对的 Z.ai 国际站美元定价是输入 $0.15、缓存输入 $0.03、输出 $0.50／百万 Tokens。它属于不同站点与货币价格，不构成国内人民币五折仍生效的证据。真正要付费时，先打开自己所用站点的控制台核价。

05 / 免费 API 的最小验证流程

  1. 来源：只从官方文档进入账号与模型目录，明确站点、地域、资格和有效期。
  2. 调用：使用最小请求，不带个人数据或公司保密资料；记录状态码与模型 ID。
  3. 对账：到控制台核对用量、缓存费用和赠额扣减顺序。
  4. 决策：比较成功率、延迟、限流和返工成本；生产项目再选择带服务保障的渠道。
