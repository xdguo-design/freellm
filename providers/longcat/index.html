LongCat API 调用

api

EndpointEndpoint
https://api.longcat.chat/openai/v1
认证Authentication
Authorization: Bearer API key

前置条件Prerequisites

  • 已注册 LongCat 平台LongCat
  • 已创建 API keyAPI key
  • 已确认账户可用额度与当前模型 IDID

操作步骤Steps

  1. 获取 API key

    从 LongCat 官方平台进入 API key 或开发者设置，创建密钥并保存为 LONGCAT_API_KEY 环境变量。

  2. 查看模型列表

    先访问官方模型接口，确认账户当前可见的模型 ID。

    可复制命令Copyable command
    curl https://api.longcat.chat/openai/v1/models -H 'Authorization: Bearer ${LONGCAT_API_KEY}'

    预期结果Expected：返回 HTTP 200 和 data 模型列表。

  3. 发送聊天请求

    把 model 改为模型列表中的真实 ID，先用短文本验证。

    可复制命令Copyable command
    curl https://api.longcat.chat/openai/v1/chat/completions -H 'Authorization: Bearer ${LONGCAT_API_KEY}' -H 'Content-Type: application/json' --data '{"model":"LongCat-Flash-Chat","messages":[{"role":"user","content":"Hello"}]}'

    预期结果Expected：响应包含 choices[0].message.content。

验证动作Validation

GET /openai/v1/models 返回 HTTP 200，随后聊天接口返回 choices；额度和模型可用性以控制台为准。

下载 LongCat-2.0 开源权重

前置条件Prerequisites

  • 已安装 Python 与 Hugging Face Hub CLIPython Hugging Face Hub CLI
  • 有足够磁盘和显存或 CPU 内存CPU
  • 已阅读模型仓库许可证See official terms

操作步骤Steps

  1. 阅读官方仓库

    先确认模型卡、许可证、硬件建议和推理方式。

    操作Action：打开 https://github.com/meituan-longcat/LongCat-2.0

  2. 安装下载工具

    在独立虚拟环境中安装 Hugging Face Hub。

    可复制命令Copyable command
    python -m pip install -U huggingface_hub
  3. 下载权重

    将权重保存到明确的本地目录，避免覆盖已有模型。

    可复制命令Copyable command
    huggingface-cli download meituan-longcat/LongCat-2.0 --local-dir ./LongCat-2.0
  4. 按仓库说明启动

    使用仓库提供的推理命令，并根据实际显存调整量化或并行参数。

验证动作Validation

下载目录包含模型配置与权重文件，并能按官方仓库示例完成一次本地推理。
