操作步骤Steps

  1. 创建 API key

    进入 SiliconFlow 控制台的 API key 页面创建密钥，并保存为 SILICONFLOW_API_KEY 环境变量。

  2. 查看模型与余额

    在模型广场确认模型 ID、上下文限制和当前免费政策；免费模型不等于无限调用。

    操作Action：打开 https://siliconflow.cn/models

  3. 发送兼容请求

    使用模型广场展示的完整模型 ID。

    可复制命令Copyable command
    curl https://api.siliconflow.cn/v1/chat/completions -H 'Authorization: Bearer ${SILICONFLOW_API_KEY}' -H 'Content-Type: application/json' --data '{"model":"Qwen/Qwen3-8B","messages":[{"role":"user","content":"Hello"}]}'

    预期结果Expected：返回 choices[0].message.content；余额不足时停止重试并查看控制台。

验证动作Validation

GET /v1/models 返回 HTTP 200，并在控制台确认请求消耗与免费政策一致。
