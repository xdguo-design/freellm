操作步骤Steps

  1. 下载安装

    从 CodeBuddy 官方产品页下载适合当前系统的 IDE，避免使用第三方安装包。

    操作Action：打开 https://www.codebuddy.cn/

  2. 登录并选择计划

    登录后选择个人体验计划，确认账户页显示的当前额度。

  3. 连接测试项目

    先打开一个不含生产密钥的项目，检查编辑器、补全和 Agent 权限。

  4. 验证免费额度

    执行一次小型补全或问答任务，回到账户页确认 credits 和 code completions 的消耗记录。

验证动作Validation

完成一次小型代码补全或问答任务，并在账户页看到个人体验计划及剩余额度。
