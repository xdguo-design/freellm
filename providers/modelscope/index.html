ModelScope API-Inference

api

EndpointEndpoint
https://api-inference.modelscope.cn/v1
认证Authentication
Authorization: Bearer access token

前置条件Prerequisites

  • 已注册 ModelScopeModelScope
  • 已创建访问 TokenToken
  • 已确认目标模型支持 API-InferenceAPI-Inference

操作步骤Steps

  1. 创建 Token

    打开 ModelScope 账户设置创建访问 Token，并保存到 MODELSCOPE_API_TOKEN 环境变量。

  2. 确认模型 ID

    从模型详情页复制模型 ID，确认该模型的 API-Inference 状态和计费说明。

    操作Action：打开 https://modelscope.cn/models

  3. 发送请求

    使用官方 OpenAI 兼容入口和模型 ID 发送请求。

    可复制命令Copyable command
    curl https://api-inference.modelscope.cn/v1/chat/completions -H 'Authorization: Bearer ${MODELSCOPE_API_TOKEN}' -H 'Content-Type: application/json' --data '{"model":"Qwen/Qwen3-8B","messages":[{"role":"user","content":"Hello"}]}'

    预期结果Expected：响应返回 choices 或官方 API 的错误详情。

验证动作Validation

GET /v1/models 返回 HTTP 200，且目标模型 ID 与模型详情页一致。
