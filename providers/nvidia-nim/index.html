操作步骤Steps

  1. 登录 NGC

    在 NVIDIA NGC 账户设置中创建 API key，并用环境变量登录容器仓库。

    可复制命令Copyable command
    echo ${NGC_API_KEY} | docker login nvcr.io --username '$oauthtoken' --password-stdin
  2. 选择 NIM 容器

    在 NGC Catalog 按模型查找对应 NIM 镜像，并确认 GPU、显存和许可要求。

    操作Action：打开 https://catalog.ngc.nvidia.com/

  3. 启动容器

    把官方文档中的镜像名、模型缓存目录和端口参数替换为当前选择，启动后从本机端口调用。

    操作Action：按照 NIM 官方 Quickstart 复制当前镜像对应的 docker run 命令。

  4. 验证服务

    查看容器日志确认服务已 ready，再访问本机健康检查或 OpenAI 兼容 models 接口。
