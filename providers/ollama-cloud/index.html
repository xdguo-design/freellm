命令行运行 Cloud 模型

cli

前置条件Prerequisites

  • 已安装 OllamaOllama
  • 已注册 ollama.com 账号ollama.com
  • 本机可访问 Ollama 服务Ollama

操作步骤Steps

  1. 安装并登录

    安装 Ollama 后，在终端执行登录命令，按浏览器提示完成账号授权。

    可复制命令Copyable command
    ollama signin
  2. 拉取 Cloud 模型

    从 Ollama Model Library 选择带 -cloud 后缀的模型，再拉取到本机客户端。

    可复制命令Copyable command
    ollama pull gpt-oss:120b-cloud
  3. 开始对话

    运行模型；推理会自动转到 Ollama Cloud，不要求本机拥有对应的大 GPU。

    可复制命令Copyable command
    ollama run gpt-oss:120b-cloud
  4. 验证结果

    输入一条简单问题，确认终端持续返回模型文本；失败时先检查登录状态和模型名。

验证动作Validation

ollama run 能返回完整回答，并且客户端没有提示需要本地模型文件。

直连 Ollama Cloud API

api

EndpointEndpoint
https://ollama.com/api
认证Authentication
Authorization: Bearer API key

前置条件Prerequisites

  • 已注册 ollama.com 账号ollama.com
  • 已在官方账户设置中创建 API keyAPI key
  • 已将密钥保存到 OLLAMA_API_KEY 环境变量OLLAMA_API_KEY

操作步骤Steps

  1. 创建密钥

    打开 Ollama 官方账户设置，创建 API key；只把它保存到本机密钥管理器或环境变量。

  2. 列出可用模型

    先调用模型列表接口，确认账户可访问的模型 ID。

    可复制命令Copyable command
    curl https://ollama.com/api/tags -H 'Authorization: Bearer ${OLLAMA_API_KEY}'

    预期结果Expected：返回 HTTP 200 和 models 列表。

  3. 发送聊天请求

    把模型 ID 替换为列表中实际可用的值，使用非流式请求便于第一次验证。

    可复制命令Copyable command
    curl https://ollama.com/api/chat -H 'Authorization: Bearer ${OLLAMA_API_KEY}' -H 'Content-Type: application/json' --data '{"model":"gpt-oss:120b-cloud","messages":[{"role":"user","content":"Hello"}],"stream":false}'

    预期结果Expected：响应包含 message.content。

验证动作Validation

GET /api/tags 返回 HTTP 200，并能在返回列表中找到要调用的模型。
