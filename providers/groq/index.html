操作步骤Steps

  1. 创建密钥

    在 Groq Console 的 API Keys 页面创建密钥，并保存为 GROQ_API_KEY 环境变量。

  2. 确认模型与限制

    从官方 Models 页面选择当前可用模型，再按 Rate Limits 页面控制 RPM、RPD 和 TPM。

    操作Action：打开 https://console.groq.com/docs/models

  3. 发送测试请求

    使用官方支持的模型 ID 发起一次短请求。

    可复制命令Copyable command
    curl https://api.groq.com/openai/v1/chat/completions -H 'Authorization: Bearer ${GROQ_API_KEY}' -H 'Content-Type: application/json' --data '{"model":"openai/gpt-oss-20b","messages":[{"role":"user","content":"Hello"}]}'

    预期结果Expected：返回 choices，并在超限时得到明确的 rate-limit 响应。

验证动作Validation

GET /openai/v1/models 返回 HTTP 200，并确认目标模型仍在官方模型列表。
