操作步骤Steps

  1. 注册并领取额度

    在 api.atria-asi.ai/console 注册（国际）或通过 discovery.intern-ai.org.cn Token Plan 入口（国内）；新用户 1 亿 Token 注册即到账，无需信用卡。

  2. 创建 API Key

    在 Keys 页创建密钥（仅创建时完整展示一次），保存为 ATRIA_API_KEY 环境变量。

    操作Action：国际控制台 https://api.atria-asi.ai/console/keys

  3. 填写客户端 Provider 配置

    Base URL 国内填 https://discovery.intern-ai.org.cn/v1，国际填 https://api.atria-asi.ai；模型 ID 固定为 Atria-Dawn-Preview；上下文 256,000；最大输出 32,768；temperature 1；工具调用开启；思考模式 reasoningEffort=auto；提示缓存关闭。

    操作Action：端点与参数细则见官方文档 https://api.atria-asi.ai/docs

  4. 发送测试请求

    发起一次短对话请求验证接入；Atria 支持思考模式（reasoning）与 function calling。

    可复制命令Copyable command
    curl https://discovery.intern-ai.org.cn/v1/chat/completions -H 'Authorization: Bearer ${ATRIA_API_KEY}' -H 'Content-Type: application/json' -d '{"model":"Atria-Dawn-Preview","messages":[{"role":"user","content":"你好"}]}'

    预期结果Expected：返回 200 与 choices[0].message.content，usage 字段显示 token 消耗，免费额度开始扣减。

  5. 按场景调参

    深度检索/深度研究/自动化任务建议开启思考模式并放宽输出上限；仅文本输入（图片/PDF 会返回 400）；Anthropic 兼容走 /v1/messages，OpenAI Responses 走 /v1/responses。

验证动作Validation

测试请求返回 200 且 content 非空；usage 扣减来自注册免费额度；控制台 Key 用量页可见本次调用。
