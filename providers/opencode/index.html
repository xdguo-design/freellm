OpenCode Zen 中使用免费模型

ide

前置条件Prerequisites

  • 已安装 OpenCodeOpenCode
  • 已完成 OpenCode 账户登录或提供商授权OpenCode
  • 已从 Zen 文档确认当前可用模型Zen

操作步骤Steps

  1. 安装 OpenCode

    按照官方安装页选择 Windows、macOS 或 Linux 安装方式。

    操作Action：打开 https://opencode.ai/docs

  2. 配置 Zen 提供商

    在 OpenCode 的 provider 设置中选择 Zen，并按官方文档完成登录或 API key 配置。

  3. 选择模型

    从 Zen 当前模型列表中选择可用模型；免费池和模型可用性不是永久承诺。

  4. 验证编辑任务

    在一个可回滚的测试仓库中让 OpenCode 读取一个文件并提出修改建议，确认模型响应和工具权限均正常。

验证动作Validation

OpenCode 能列出 Zen 模型并完成一次只读代码分析；写入操作前先检查 diff。

查找 Muse Spark 1.3

ide

前置条件Prerequisites

  • OpenCode 或其他已启用 Meta provider 的客户端OpenCode Meta provider
  • 账户所在地区与账户类型满足模型可见条件See official terms

操作步骤Steps

  1. 打开模型设置

    进入客户端的模型或 provider 设置，刷新远端模型列表。

  2. 搜索模型名

    搜索 Muse Spark 1.3；如果没有出现，先检查 Meta provider 是否已启用以及客户端版本。

  3. 确认可用性

    打开模型详情查看上下文、价格、访问范围和调用方；不要把第三方展示的名称当作 Meta API 的永久免费承诺。

    操作Action：打开 https://research.meta.ai/blog/introducing-muse-spark-1-3

  4. 运行小任务

    使用短上下文执行一次只读问答，确认响应来自所选模型而非客户端自动回退模型。

验证动作Validation

客户端显示的模型 ID、provider 和响应元数据都指向 Muse Spark 1.3；缺失时记录为当前不可用。
