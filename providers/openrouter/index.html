前置条件Prerequisites

  • 已注册 OpenRouterOpenRouter
  • 已创建 API keyAPI key
  • 已从模型页确认当前免费模型 IDID

操作步骤Steps

  1. 创建 API key

    进入 OpenRouter Keys 页面创建密钥，并将它放入 OPENROUTER_API_KEY 环境变量。

  2. 选择免费模型

    在官方 Models 页面筛选价格为 0 的模型；免费标记和可用性会变化，不要长期写死目录中的模型。

    操作Action：打开 https://openrouter.ai/models?max_price=0

  3. 发送 OpenAI 兼容请求

    将 model 替换成模型页显示的完整 ID。

    可复制命令Copyable command
    curl https://openrouter.ai/api/v1/chat/completions -H 'Authorization: Bearer ${OPENROUTER_API_KEY}' -H 'Content-Type: application/json' --data '{"model":"openai/gpt-oss-20b:free","messages":[{"role":"user","content":"Hello"}]}'

    预期结果Expected：响应包含 choices[0].message.content。

验证动作Validation

GET /api/v1/models 返回 HTTP 200；随后聊天请求返回 choices 数组。
