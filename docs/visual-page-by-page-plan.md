# FreeLLM Aurora 视觉重构阶段计划

更新时间：2026-09-23

## 总体原则

本轮只做一套样式：**Aurora / 极光**。

开发方式固定为：**先定样式系统 → 首页 → 模型页 → Skills → Tools → Workflows → 更新页 → 关于页 → 全站统一回归**。

每个页面都必须独立完成“设计收敛、开发、桌面/平板/手机视觉回归、修复、验收”，通过后才进入下一页。第二套主题暂不开发。

## Phase 0：Aurora 设计系统

冻结以下规则：

- 深海军蓝侧栏 + 明亮极光主画布
- 蓝 / 青蓝主色，紫粉与薄荷绿只做层次色
- 统一字体层级、圆角、边框、阴影、间距
- 统一按钮、Chip、输入框、Tab、卡片、Hero
- 桌面 / 平板 / 手机使用同一套语义 Token，不复制页面结构

## Phase 1：首页

范围：导航、Hero、今日/最新、筛选、分类、热门资源、资源卡、学生优惠、对比/下载/FAQ。

验收重点：

- 今日 / 最新位于 Hero 后的第一信息层
- 学生优惠不抢首页主层级
- 同行资源卡等高，底部操作对齐
- 筛选器紧凑，不形成第二个大 Hero
- 1440 / 1024 / 390 三档均无页面级横向溢出

## 后续页面

- Phase 2：模型页
- Phase 3：Skills
- Phase 4：Tools
- Phase 5：Workflows
- Phase 6：更新页
- Phase 7：关于页
- Phase 8：全站统一回归

## 页面完成定义

一个页面只有同时满足以下条件才算完成：

1. 视觉符合 Aurora 基线
2. 核心功能没有回归
3. 卡片高度与底部操作规则通过
4. 390px 无页面级横向滚动
5. 页面截图人工检查通过
6. 自动化页面契约测试通过

当前只执行 **Phase 0 + Phase 1：首页**。
