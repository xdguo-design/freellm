## 1. 通用英文产品介绍

### 一句话

FreeLLM is a verified index of free AI models, coding IDEs, API quotas, open weights, and student offers.

### 短描述

Find usable free AI resources with official links, quota rules, regional access notes, and verification dates.

### 150 字英文介绍

FreeLLM helps developers and students discover practical free and low-cost AI resources. It indexes free model quotas, coding IDEs, API trials, downloadable open weights, student offers, and limited-time promotions. Each entry links to an official source and separates recurring free access, one-time trials, paid promotions, downloadable weights, and pay-as-you-go plans. Visitors can filter the catalog by use case and check regional availability, registration requirements, quota limits, renewal terms, and the last verification date before signing up. The project is built for people who want to compare real access paths instead of reading vague “free AI tools” lists.

### 中文介绍

## 3. V2EX「分享创造」发帖

### 标题

我做了一个免费 AI 资源索引：把额度、地区限制和官方入口整理到一起

### 正文

大家好，最近做了一个小项目 FreeLLM：

https://freellm.top/

它主要解决一个很具体的问题：现在很多“免费 AI”信息只写一句“有免费额度”，但没有说清楚地区、注册方式、是否需要绑卡、额度怎么重置、试用什么时候结束，实际用起来很容易踩坑。

目前站里整理了 36 个条目，主要包括：

- 免费模型和 API 额度
- 免费编码 IDE 和代码助手
- 学生优惠与限时活动
- 可以下载的开放权重
- Qwen、豆包、GLM、Mistral、Groq、Cerebras、OpenRouter 等相关入口

每条记录会尽量保留官方链接，并区分长期免费、一次性试用、首月优惠、开放权重和低价按量付费。页面还会记录地区、注册要求、额度限制和最后核验时间。

GitHub 仓库：

https://github.com/xdguo-design/freellm

目前还是一个人维护，欢迎大家帮忙指出失效链接、过期额度和遗漏的平台。也想听听大家觉得这个索引最应该补哪些筛选条件。

### 发布后回复模板

感谢反馈。我会优先核对官方定价页和文档，不会为了把条目写成“免费”而补猜测数字。确认后会在对应条目里更新核验日期和限制条件。
