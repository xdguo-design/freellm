MiMo-V2.6 Flash：
1M 上下文的全模态模型，哪里能免费用？

小米在 9 月 22 日发布并开源 MiMo-V2.6 系列。Flash 主打高频调用与大规模任务：原生支持文本、图片、视频和音频输入，同时保留推理、工具调用与结构化输出能力。

先说结论：MiMo-V2.6 Flash 的小米官方 API 不是免费 API，它按 Token 计费；目前我们核验到的明确免费入口，是 OpenCode Zen 的 MiMo-V2.6-Flash Free，官方标注为限时免费。如果你愿意自己部署，Hugging Face 还有官方开源权重，但“权重免费”不等于“推理算力免费”。

01 / 它到底是什么

Flash，不只是“快一点的 Pro”

根据小米官方模型页，MiMo-V2.6-Flash 的上下文窗口为 1M tokens，最大输出 128K tokens；输入模态包括 Text、Image、Video、Audio，输出为文本。官方还列出了深度思考、Tool Call、Streaming、Web Search、Structured Output、Context Caching 等能力。

02 / 免费入口

目前真正能明确写“免费”的，是这三类

① OpenCode Zen · MiMo-V2.6-Flash Free

OpenCode 官方 Zen 文档当前列出模型 ID mimo-v2.6-flash-free，并把 Input、Output、Cached Read 都标为 Free；同时明确说明这是 limited-time free，没有承诺永久免费。

注意：OpenCode 说明免费期交互数据可能用于模型改进，不要提交个人、商业机密或敏感内容。

② Puter.js · 浏览器免费试用

Puter Developer 当前提供 xiaomi/mimo-v2.6-flash 浏览器 Playground。官方页面写明“no API keys or setup required”，免费账户带 AI allowance；这是第三方托管入口，不等同于 Xiaomi 官方 API 免费。

③ Hugging Face · 官方开源权重

XiaomiMiMo 官方发布了 MiMo-V2.6-Flash-RL 权重，可用 vLLM / SGLang 等方式自部署。这里“免费”的是模型权重与开源使用方式；GPU、服务器、电费和运维成本仍然存在。

03 / 别把它写成“官方 API 免费”

小米官方 API 是付费的

MiMo-V2.6-Flash 官方 API 采用 Pay-As-You-Go。当前官方美元价：缓存命中输入 $0.0028 / 1M tokens，普通输入 $0.14 / 1M tokens，输出 $0.28 / 1M tokens。它确实很便宜，但“便宜”和“免费”是两件事。

04 / FreeLLM 核验结果

我们这次到底测了什么

  • 核对小米官方发布页：V2.6 系列已发布并开源，API 模型名为 mimo-v2.6-flash。
  • 核对小米官方模型页：1M context、128K max output、100 RPM、10M TPM，以及官方 API 价格。
  • 访问 OpenCode Zen 公开 /v1/models：实时目录中存在 mimo-v2.6-flash-free。
  • 核对 OpenCode 官方定价：该 Free 变体 Input / Output / Cached Read 均为 Free，且官方标注为限时免费。
  • 核对 Hugging Face 官方模型仓库：可按官方示例用 vLLM / SGLang 自托管。
测试边界：本轮没有用户的 OpenCode Zen API Key，因此没有伪造“实际生成成功”。当前已完成公开模型目录、官方文档、定价和访问路径核验；真正的端到端推理请求仍需凭据后再补最后一步。
05 / 怎么选

三种使用方式，一句话区分

想先免费体验：看 OpenCode Zen 或 Puter.js Playground；想稳定接入生产 API：用 Xiaomi MiMo Open Platform，按量付费；想自己掌控部署：下载 Hugging Face 官方权重，但要自己承担算力。
