# MiMo TTS FreeLLM 实测样音设计

## 目标

为 Xiaomi MiMo V2.5 TTS 详情页增加可试听的 FreeLLM 自测样音和可追溯的测试记录，明确区分官方规格、真实调用结果和未验证项目。该页面作为后续模型/工具详情页加入自测内容的样板。

## 方案

- 采用固定中文测试文本，由 FreeLLM 使用 `mimo-v2.5-tts` 生成并保存静态 WAV 样音；页面提供原文、音频播放器及下载入口。
- 在样音旁展示测试时间、模型、音色/风格、实际请求耗时、响应格式和费用核验结果。每项只记录真实观测结果，未知值显示“未验证”。
- API Key 只从本地环境变量读取，绝不写入页面、仓库或构建产物。当前未配置 Key，因此先保留“等待真实 API 测试”的透明状态；不使用浏览器语音合成或官方演示音频伪装成 FreeLLM 样音。
- 在 `data/offers.json` 的该 offer `freeLLMTest.ttsSample` 字段记录固定文本、模型、生成状态、静态音频路径和真实测量值；扩展 `scripts/build_seo_pages.py` 渲染此可选字段。没有 `ttsSample` 的其他资源页不受影响。

## 固定样本文本

“清晨的阳光落在窗边，街道慢慢苏醒。今天，我们用同一段文字，听听不同音色怎样表达温柔、清晰和自然。”

## 验收标准

1. 凭据缺失时展示固定文本和清晰的“样音待实测”状态；真实调用成功并配置音频路径后，详情页能播放真实 MiMo API 生成的 WAV，并展示生成原文。
2. FreeLLM 的日期、模型、音色/风格、耗时和费用状态可追溯；没有证据的数据不显示为通过。
3. 页面和静态产物中没有 API Key；音频样本文件和元信息均可随静态站点发布。
4. API 调用失败时不生成“通过”结论或损坏的音频播放器。
