# FreeLLM 首页下半部分样式设计

## 目标

参照用户提供的截图，将 FreeLLM 首页从“学生优惠”开始的下半部分整理成清晰、紧凑的浅蓝目录页面。顶部导航、Hero、统计、分类筛选及资源目录交互不在本次范围内。保留现有真实资源、文案、链接和交互，不补造截图中未存在于当前数据里的产品或条件。

## 页面范围与实现边界

- 目标页为 `design/free-china-ai-index.html`，通过现有首页样式上下文 `body[data-fl-section="home"]` 作用域限定视觉规则。
- 现有 HTML 已包含学生优惠、低价比较卡与表格、本地下载入口、说明卡、FAQ 折叠项和页脚。本次以样式为主，不改数据模型，不调整上半页顺序和现有交互。
- 优先复用 `.student-panel`、`.compare-panel`、`.cheap-lane`、`.compare-table`、`.download-panel`、`.download-list`、`.catalog-faq`、`.faq-list` 与 `.footer` 等现有结构；不重做 `reference-shell.js` 的首页装配。

## 视觉规格

- 延续雾白浅蓝背景、深海军蓝标题、明亮蓝色链接与按钮、浅色边框、柔和阴影、圆角白卡片。
- 学生优惠段落采用左右分栏：左侧标题、说明和筛选入口，右侧已有优惠项以卡片呈现；标题前保留小号蓝色编号/英文眉题。
- 最便宜入口段采用左侧标题说明、右侧三列入口卡；下方对比表横向铺满内容区，强调地区、价格/有效期和判断标签。免责声明保持易读但弱化层级。
- 本地下载列表采用连续的白色行卡，模型名与来源在左，模型元数据居中，官方链接或动作按钮靠右；窄屏转为堆叠布局。
- “如何阅读”段先展示四张说明卡，再展示紧凑的原生 `<details>` FAQ 行；页脚分成来源/更新时间信息和法律导航两排。
- 桌面保持截图的密度和横向对齐；中等宽度减少列数；手机端各区块单列，表格允许横向滚动，交互控件保持可触达。

## 约束与验收

- 仅在首页作用域下改视觉样式，避免影响模型、工具、Skills 等其他页面。
- 不修改筛选、跳转、折叠 FAQ、对比表数据、本地资源列表生成逻辑。
- 不扩充当前展示项来硬凑截图数量；布局根据现有数据自然适配。
- 在桌面和手机宽度检查各区块层级、横向溢出、表格可读性和页面内链接/折叠控件可用性。
