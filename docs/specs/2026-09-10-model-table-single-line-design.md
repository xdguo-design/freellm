# 模型表格单行显示设计

## 目标

厂家页和模型聚合页的模型名称、模型 ID 保持单行，过长内容显示省略号；完整内容仍通过原生悬停提示可查看。

## 方案

- 给模型名称和 ID 容器增加专用 class。
- 使用 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis` 稳定行高。
- 保留现有链接、完整文本和数据，只增加 `title` 属性作为可访问的完整值提示。
- 在两处生成目录表的 CSS 中同步规则，避免厂家页与聚合页视觉不一致。

## 验收标准

1. 长模型名称和 ID 不再换行。
2. 截断文本仍可点击进入原页面，悬停可看到完整值。
3. 现有模型表格、构建检查和测试全部通过。
