# Skills 中文展示文案设计

## 目标

让 `/skills/` 面向中文用户时展示易读的中文 Skill 简介，同时保留上游英文描述、SKILL.md 原文和 GitHub 来源。英文模式继续显示原文，不改变 Skill 的实际触发规则。

## 方案

在 `data/skills-i18n.json` 新增按 Skill ID 索引的 `description_zh` 展示层翻译。构建器加载并校验该映射后，将双语字段写入页面数据：卡片和详情使用 `<span lang="zh-CN">` / `<span lang="en">`，由现有 locale 脚本控制显示。搜索同时覆盖中英文描述，确保中文关键词可找到对应 Skill。

不修改 `data/skills.json` 的上游原文，不自动调用客户端翻译服务，不翻译懒加载的 SKILL.md 原文；这样可以保留来源可追溯性并避免运行时网络依赖。

## 交互与内容规则

- 中文默认显示 `description_zh`；英文显示 `description`。
- 中文翻译使用“用途 + 触发场景 + 输出/限制”的短摘要，卡片继续最多显示 4 行。
- 详情弹窗显示同一语言的简介，并提供独立的 SKILL.md 原文区域。
- 缺少翻译或翻译为空时构建失败，而不是静默回退到英文，避免中文页面再次出现未翻译内容。

## 验收标准

1. 68 个 Skill 均有非空中文简介，ID 与目录一一对应。
2. 中文生成页包含中文简介，英文生成页仍包含英文原文。
3. 页面搜索可匹配中文简介和英文原文。
4. 既有卡片高度、视觉预览、原文加载、评价和 GitHub 链接行为不回归。
5. 全量单元测试、SEO 生成检查和线上 HTTP 检查通过。
