# About 页面参考稿高保真改造实施计划

> **给代理执行者：** 在当前会话按勾选逐步执行。任务使用 `- [ ]` 跟踪。

**目标：** 让 `/about/` 在桌面和移动端清楚地呈现获批截图中的布局与视觉层级。  
**架构要点：** About 页面结构保留在静态 HTML，页面专属视觉规则集中在独立 CSS 文件中。复用全站导航、语言切换和现有图片资源，避免继续向通用样式表追加 About 专属覆盖。  
**技术栈：** 静态 HTML、CSS、现有 JavaScript；视觉核对使用已有 Playwright Python 环境。  
**关联设计文档：** `docs/specs/2026-09-30-about-reference-redesign-design.md`

## 文件职责

- 修改 `about/index.html`：将当前四段正文改为目标页面的主视觉、价值卡、引用、统计卡、原因/原则/流程/独立性/联系模块，并保留中英文和链接。
- 修改 `js/reference-shell.js`：移除 About 页面专属内容注入与内联尺寸调整，保留通用顶部栏、页脚和语言功能。
- 新建 `css/about-reference.css`：集中实现 About 页面桌面与移动样式，避免影响其他页面。
- 修改 `about/index.html` 样式引用：加载新的 About 专属样式。
- 生成 `.tmp-compare/about-reference/`：保存桌面/移动页面截图和布局测量结果；该目录为可重建的本地验证产物。

**涉及文件：** 新建 `css/about-reference.css`

- [ ] **步骤 1：** 所有规则限定在 `body[data-fl-section="about"]`，重设页面容器、主视觉图层、标题和正文层级。
- [ ] **步骤 2：** 使用 CSS Grid 实现价值卡三列、统计卡四列、原因卡三列、原则卡四列、更新步骤四列及联系卡两列；窄屏断点逐步改为两列和一列。
