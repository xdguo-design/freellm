> **给代理执行者：** 在当前工作区逐个完成行为切片；每个切片遵循 RED → GREEN → REFACTOR。

**目标：** 保留 `/skills/` 原有 Skill 清单页，新增 `/skills/lab/` 作为由 FreeLLM 策划的 6 套工作流配方页，并把 110 条 Skill 收入新页的默认折叠组件库。

**技术栈：** Python 3、静态 HTML/CSS/JavaScript、`unittest`；验证命令为 `python -m unittest tests.test_skills_page -v`、`python -m unittest tests.test_build_static tests.test_e2e_static -v` 和 `python scripts/build_seo_pages.py --check`。
