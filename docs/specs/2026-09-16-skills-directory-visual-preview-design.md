# Skills 目录紧凑卡片与视觉预览设计

## 目标

降低 `/skills/` 列表卡片的纵向占用，并让技能详情弹窗在阅读原文前提供可理解的输出样式预览。

## 方案

- 卡片采用内容高度而不是行内最长卡片的拉伸高度；描述最多显示 4 行，完整描述保留在详情弹窗。
- 卡片减少内边距和区块间距，保留分类、状态、热度、入口和 GitHub 操作。
- 详情弹窗新增“视觉预览”区：使用已有 `format`、`styles.summary`、`styles.items`、`styles.total` 数据生成 CSS 小样式板，不依赖外部图片。
- 没有预设视觉主题的技能仍展示其输出形态（文档、代码、表格等）的结构预览，并明确这是结构示意，不冒充真实产物截图。
- 原文和社区评价继续保留在视觉预览之后。

## 数据与交互

技能页面生成器负责输出预览容器和 CSS；页面脚本根据当前 Skill 填充输出类型、摘要、样式标签和结构示意。缺少样式数据时显示统一的通用预览，不隐藏整个预览区。

## 验收标准

1. 桌面端三列卡片不再因最长描述统一拉高，卡片描述最多占 4 行。
2. 移动端卡片仍为单列，内容不溢出，操作入口可点击。
3. 点击任一 Skill 后，弹窗包含 `视觉预览`，并展示输出格式；有样式数据时展示样式标签。
4. `SKILL.md` 原文、安装命令、GitHub 链接和社区评价行为不回归。
5. 生成器测试和完整测试套件通过。
