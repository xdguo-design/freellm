# 页脚公开联系邮箱设计

## 目标

在首页页脚公开站点维护者的联系邮箱，方便用户反馈资源错误、失效链接或提交新资源。

## 方案

- 在当前可见的 `catalog-app` 页脚加入 `mailto:xdguo0527@gmail.com` 链接。
- 英文显示 `Contact: xdguo0527@gmail.com`，中文显示 `联系我: xdguo0527@gmail.com`。
- 保持邮箱文本大小写不被页脚的全大写样式改写；不新增表单、第三方收集或后端接口。

## 验收标准

1. 中文和英文路由均显示邮箱。
2. 点击邮箱使用 `mailto:` 协议打开邮件客户端。
3. 现有搜索、筛选、详情抽屉和语言切换功能不受影响。
4. 静态契约测试覆盖邮箱地址和双语标签。
