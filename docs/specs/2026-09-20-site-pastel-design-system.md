# FreeLLM 全站浅蓝手绘产品设计系统

## 设计目标

把 FreeLLM 的首页、目录、详情、Skills、Skill Lab、工具与说明页统一成一套轻、清晰、可信的产品界面。视觉参考为用户提供的浅蓝医疗产品页：大留白、柔和卡片、蓝/粉/薄荷状态色、少量手绘批注。

## 核心原则

1. **信息先于装饰**：高密度模型、Offer 和 Skill 数据仍要快速扫描。
2. **卡片分层**：页面背景、主内容容器、信息卡三级层次，不用重阴影。
3. **蓝色主动作**：主 CTA 和选中态统一蓝色；粉色用于强调，薄荷用于成功/可用，黄色用于提示。
4. **手绘只做记忆点**：Hero 与章节标题允许少量手写批注/下划线；表格、正文、操作区不使用手写字体。
5. **统一圆角**：大区块 24px，普通卡片 18px，输入与按钮 12–14px。
6. **默认浅色**：保留深色模式，但品牌主视觉以浅蓝白色为基准。
7. **移动端不是缩小桌面**：固定左栏在 <=1100px 转为顶部横向导航；<=700px 降低圆角与内边距并转单列。
8. **可访问性**：保留 focus-visible；支持 prefers-reduced-motion；语义状态不能只靠颜色。

## 页面族

### 首页
Hero 用浅蓝到白再到浅粉的柔和渐变；资源分类、精选资源和 Offer 卡片统一圆角、边框和 hover。原有筛选与数据逻辑不变。

### 模型 / Provider / Offer / Guide
主页面保留 SEO 结构，将 main 下的章节拆成视觉卡片；表格使用蓝灰表头、圆角外框、行 hover；状态标签使用语义色。

### Skills
保留搜索、分类、详情弹窗和 Skill 数据。Hero、筛选、卡片、弹窗统一新主题；FreeLLM 实测数据后续可直接复用相同组件层级。

### Skill Lab
隐藏旧的独立左侧栏，复用全站导航。工作流卡片、步骤节点和组件库使用蓝/粉交替背景。

### 工具
工具目录与单工具页都继承全站主题。工具输入输出区仍保持高可用性，不做纯装饰性复杂动效。

### 法务 / About / 收藏
正文使用白色半透明主卡，章节使用轻色信息卡；避免长文本直接铺在纯白大页面上。

## 接入方式

当前页面统一通过 /js/freellm-sync.js 加载 /css/freellm-pastel-ui.css。生成器同时会把 CSS link 写入后续重新生成的静态页，以减少首屏样式切换并保证未来页面自动继承设计系统。
