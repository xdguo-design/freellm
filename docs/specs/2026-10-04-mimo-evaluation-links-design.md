# MiMo 评测链接入口设计

## 目标

把用户提供的 Xiaomi MiMo 公众号评测链接放入首页“今日 AI 热点”，并作为 MiMo 模型更新记录的第二个参考链接展示。

## 设计

- 首页继续保留当前 5 篇热点，在卡片列表末尾追加第 6 篇；中性标题使用“MiMo 模型评测”，不臆造微信文章标题或正文结论。
- 更新记录目标为 `MiMo-V2.6-Flash`（`data/daily-log/2026-09-25.json`）。保留现有官方模型页作为第一个链接，在其后增加用户提供的公众号评测链接。
- 更新行在模型名称下方显示“官方模型页”和“公众号评测”两个链接。数据放在该事件的 `details.relatedLinks`，渲染器仅在存在该字段的记录下显示链接，避免影响其他历史记录。
- 变更首页源文件、MiMo 日志数据、更新页渲染器及其当前生成输出；不运行全站生成器覆盖工作区已有修改。

## 验收

1. 首页热点卡片共 6 张，原有最后一篇 GitHub Actions 卡片保留。
2. 新卡片链接到用户提供的微信文章。
3. `/logs/` 中 MiMo-V2.6-Flash 更新行展示官方模型页在前、公众号评测在后的两个链接。
4. 其他更新记录内容不变。
