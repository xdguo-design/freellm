# 四个页面原型像素校准设计

- 日期：2026-09-30
- 状态：实施范围已确认，待文档复审及用户审阅
- 视觉基准：用户本次提供的四张页面原型图

## 目标

重新逐页比较工具箱、工作流、更新和关于页面，使页面布局和视觉样式严格贴近对应原型，包括位置、尺寸、比例、颜色、字体、间距、卡片密度、插图及页脚构成。

## 范围与边界

- 工具箱：`tools/index.html` 及其直接关联的样式和资源。
- 工作流：`skills/lab/index.html` 及其直接关联的样式和资源。
- 更新：`logs/index.html` 及其直接关联的样式和资源。
- 关于：`about/index.html` 及其直接关联的样式和资源。
- 以用户提供的原型图作为唯一视觉依据；沿用现有页面数据和交互语义，不自行补造视觉元素或另行设计版式。
- 保留工作区既有未提交改动。仅修改上述页面及其确有必要的共享样式/图片引用；每项共享样式变更须以这四页为作用范围，避免覆盖无关页面表现。
- 原型中的视觉区域与当前结构不一致时，可调整对应页面的标记结构和样式，以还原原型所示布局；不做无关重构。

## 实施方式

先按页面记录当前实现与原型的可见差异，再逐页校准侧栏、顶栏、Hero、统计/筛选区、内容网格、辅助区、页脚的尺寸、坐标关系、间距、颜色、字体和插画。优先使用现有 DOM 与图片资源；只有当前资源无法表达原型时才新增或替换局部素材。保留小屏下基本可读和交互可用。

- 使用同一 Chromium 版本和同一字体环境，浏览器缩放 100%、设备像素比 1，视口宽度和高度分别匹配对应参考图像素尺寸；截图前等待字体、图片和页面资源加载完成，并禁用 CSS 动画、过渡及闪烁光标；截取从页面顶部开始的完整页面，隐藏滚动条后比较，页面截图和原图不做非等比缩放。
- 对比前统一参考图与页面截图的宽度和缩放；检查各区块边界、栏宽、纵向节奏、卡片网格、插图落点、颜色及页脚高度。
- 参考图中的示例数据不要求替换当前业务数据；验收重点是页面样式、结构占位和排列与原型对应。
- 不把整页截图铺作页面背景，页面内容与原有交互仍由当前 HTML/CSS/JavaScript 提供。

## 差异判定

- 主要区块边缘、网格列数、宽高、位置和间距与参考图的偏差不超过 1 CSS px；背景、边框和主要文字颜色与取样值的单通道 RGB 偏差不超过 2。
- 对参考图与页面截图配准后，遮罩掉文字字形抗锯齿边缘及动态示例数据文字，比较其余视觉区域的 SSIM，目标不低于 0.98；同时检查 50% 透明度叠图及差异图，不接受可见的区块错位、尺寸不符或新增视觉元素。
- 字体渲染造成的字形边缘差异，以及实际数据与原型示例不同造成的文字差异不计入像素阈值；文字块的位置、字号、行高、颜色和占用空间仍须逐项匹配。
