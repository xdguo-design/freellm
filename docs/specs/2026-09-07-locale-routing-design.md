# 原型语言路由设计

## 目标

让首页默认使用英文，并根据访问地址或浏览器语言自动选择中文/英文；用户可以在右上角手动切换，且不影响现有搜索、筛选、排序、详情抽屉和数据读取。

## 语言解析规则

语言优先级固定为：

1. URL 查询参数：`?lang=zh-CN` 或 `?lang=en`。
2. URL 路径段：路径包含 `/zh/` 或 `/en/` 时使用对应语言。
3. 用户本地选择：读取 `localStorage` 中的 `free-ai-index-locale`。
4. 浏览器首选语言：`navigator.languages` 中首个 `zh-*` 使用中文，其余使用英文。
5. 默认英文。

只接受 `zh`、`zh-CN`、`en` 和 `en-US`，其他值回退到英文。用户点击语言切换时更新 URL 的 `lang` 参数、`<html lang>` 和本地存储，不重新加载页面。

## 页面范围

- 翻译原型固定界面：导航、英雄区、筛选栏、分类、热门资源、学生优惠、资源列表表头、空状态、价格比较、下载区、FAQ、页脚和语言按钮。
- 模型名、公司名、官方来源、额度与地区证据保留数据源原文，避免把价格或资格条件机器翻译成错误信息。
- 页面加载后根据当前语言刷新动态结果计数、排序选项、详情抽屉固定标签和本地时间提示。

## 交互与兼容性

语言选择器放在现有 header actions 内，使用按钮并提供 `aria-label`。英文模式显示 `中 / EN`，中文模式显示 `EN / 中`。已有锚点、筛选参数和搜索参数继续保留，切换语言只追加或更新 `lang` 参数。

## 验收标准

- 无语言信号访问页面时，`<html lang>` 为 `en`，页面固定界面为英文。
- `?lang=zh-CN` 访问时，`<html lang>` 为 `zh-CN`，页面固定界面为中文。
- 浏览器语言为中文且无 URL/本地选择时，自动使用中文；其他浏览器语言使用英文。
- 手动切换会保留当前页面的 hash、搜索内容和筛选状态。
- 现有静态契约、数据校验和详情按钮行为继续通过。
