# 关于页截图复刻设计

- 日期：2026-09-30
- 状态：已确认

## 目标

将正式 `/about/` 页面逐项复刻为用户提供的 860 × 1828 截图。截图是文字、数据、区块顺序、图片素材和视觉样式的最终基准；`design/about.html` 的内容结构不同，不直接作为页面模板。当前 HTML、动态注入文案及原型素材只有在与截图一致时才复用；不一致时以截图为准。

## 范围

- 复刻页面顶部搜索与账户操作、左侧固定导航与山景、英雄区、三项价值卡、引用条、统计卡片、四组说明卡、社区反馈、品牌页脚及底部山景。
- 对齐截图中的文字、顺序、图标、图片、颜色、字体、卡片尺寸、间距和页面纵向节奏。
- 保留正式页面的 SEO 元信息、URL、共享站点导航、语言与主题能力，以及各反馈/联系入口。
- 将 About 页面内容以静态语义 HTML 呈现；避免依赖 `reference-shell.js` 在页面加载后拼装主要内容。
- 限定改动在 About 页面及其专属样式/脚本分支；保留工作区其余未提交改动。

## 实现方案

以附件截图为全部基准，把正式页重组为与截图相同的组件顺序，并逐字、逐项核对各区块中文文案、统计数字和素材；截图未标出的细节才复用与其兼容的现有内容。将 About 专属布局与样式隔离到明确的页面类名，避免通用页面规则改变截图比例。保留共享导航 DOM 和切页生命周期，仅调整 About 所需的顶栏操作和页面挂载行为。移除已由静态 HTML 提供的 About 专属动态重复注入。

## 验收标准

- 在与参考图相同的视口/显示比例下，对照 860 × 1828 附件，页面整体布局、内容顺序与文案、导航和装饰素材逐项一致。
- 顶栏和侧栏可见且不遮挡内容；侧栏保持固定，正文卡片与页脚完整显示。
- 主导航切页后 About 页面结构和交互正常；直接打开 `/about/` 仍显示完整页面。
- SEO 元信息、语言切换、主题切换、反馈与邮件入口继续可用。

## 验证方式

使用浏览器按附件相同视口截取正式页，逐区块比较边界、位置、尺寸、颜色、字号、行高、图片裁切与内容；结合浏览器检查确认响应式布局和导航行为。只对实际发现的偏差做迭代。
