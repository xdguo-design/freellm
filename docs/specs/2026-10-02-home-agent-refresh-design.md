# 首页 Agent 热门资源与内容层级调整

## 目标

让首页近期资源更贴近用户关注的 AI Agent / Bot，并让更新日期和原创文章更容易辨认。

## 设计

- 将资源筛选入口“AI IDE”改为“AI Agent”，资源卡片更新为近期 Agent 产品；优先使用已有详情页的 Manus、WorkBuddy 与 Xiaomi MiMo Desktop，并加入 Meta Muse、Kimi Work 等有官方入口的产品。Muse 使用 Meta 官方入口，卡片明确标示目前地区可用范围。其余展示项从已有 Agent 资源中选择，不编造热度或可用状态。
- 更新表格统一显示年月日/月份日期，不使用“今天”“N 天前”等相对描述。按原型日期 2026-10-02，将“今天”改为“10 月 2 日”，“2 天前”改为“9 月 30 日”。首页近期文章卡也显示已知发布日期；没有可靠日期的条目不显示相对日期。
- 热点文章区采用编辑精选结构：第一篇文章作为主卡，其余文章作为紧凑副卡。桌面端维持一张主卡加四张副卡的视觉层级；窄屏降为单列并按文章顺序阅读。保留文章标题、日期、摘要、主题标签和原文链接。

## 交互与边界

- “AI Agent”筛选只应展示标记为 Agent 的资源卡片，资源卡片使用可见的类别标记，不依靠标题关键词判断。
- 不改动全站资源数据、更新记录、文章正文或其它首页区块。
- Muse 的地区和开放状态按官方当前说明展示；其它产品沿用项目现有详情页和核验信息。

## 验收标准

1. 首页资源精选区不再展示 Agnes AI、Notion AI、Midjourney 等与该 Agent 精选目标不符的旧卡片；共保留六张 Agent 卡片，Muse 与本地已收录的 Agent 产品有清晰入口，且不展示无来源的热度数值。
2. 点击“AI Agent”能筛出 Agent 资源，筛选状态有可访问的选中状态。
3. 更新表格和近期文章卡的日期使用明确日期或省略，不含“今天”或相对天数。
4. 热点文章中第一篇视觉主次突出，其余文章仍可完整阅读并保留原链接；小屏下不出现横向溢出。

## 涉及文件

- `design/free-china-ai-index.html`：精选资源内容、分类入口、更新表格日期和文章结构。
- `css/home-prototype-exact.css`：文章编辑精选布局、资源卡片差异化和响应式样式。
- `js/homepage.js` 与其页面引用副本 `js/homepage.7eeed4fbb5.js`：让 Agent 标签作为真实资源分类参与筛选。
