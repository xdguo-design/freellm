# 首页按原型收敛设计

## 目标

让首页与用户提供的完整原型一致，并将精选模型集中在模型页，避免首页重复铺列大量模型。

## 页面范围

- 首页保留原型中的 Hero、概览、5 条 AI 热点、精选资源卡片、热门分类、8 行最新更新、社区福利卡片和页脚。
- “精选资源”按原型保留工具与应用卡片；精选模型由 `/models/` 展示。
- 隐藏原型页脚之后附加的完整 offer 目录及其价格比较、下载、FAQ 等目录专属区块。
- 原型中的模型热点和 8 行更新记录继续保留；它们是动态资讯/更新，不是精选模型列表。

## 实现边界

- 页面布局仍以 `design/free-china-ai-index.html` 的 `.prototype-home` 为首页内容源。
- 隐藏规则限定在首页的 `data-reference-style="v1"`，不影响 `/models/` 与其他资源页面。
- `/models/` 保持现有精选模型卡片和完整目录入口。

## 验收标准

1. 首页在社区福利与原型页脚后结束，不再出现第二套完整资源目录。
2. 首页精选资源卡片仍展示原型中的工具与应用。
3. 精选模型从模型页进入；首页只保留原型中的热点与最新更新记录。
4. 首页改动不影响模型库页面。
