# Skills 页面原型复刻设计

- 日期：2026-09-30
- 状态：已获用户确认，待审阅
- 视觉基准：用户提供的 Skills 页面原型图；仓库中的 `assets/reference/skills-prototype-screen.png` 用于对照现有原型素材

## 目标

修复 FreeLLM Skills 页面，使桌面端页面的布局、视觉层级、颜色、字体、留白、卡片、图标和插画位置尽可能按原型 1:1 还原。页面仍展示当前真实技能目录与详情，不把原型截图作为整页背景，也不改变已有业务数据或交互语义。

## 范围与实现边界

- 以 `skills/index.html` 当前页面结构和 `css/aurora-skills.css` 的 Skills 专属规则为主要实现位置。
- 允许在必要时调整 Skills 页使用的图片资源引用，以及与页面直接相关的局部标记结构。
- 避免改动其他页面共享样式；如发现公共样式级联覆盖 Skills 页，只添加带 Skills 页面作用域的覆写。
- 保留现有技能筛选、搜索、排序、网格/列表切换、详情选择、收藏和详情面板交互及页面数据。
- 不做与原型复刻无关的重构或新增功能。

## 页面构成

按原型顺序校准这些区域：

1. 深色固定左侧导航、品牌标志、主题切换和底部品牌文案。
2. 顶部搜索栏、通知与登录/注册按钮。
3. Skills Hero 标题、说明、操作按钮及右侧插画。
4. 数据统计行和精选合集卡片。
5. 全部技能区：分类筛选、排序/视图控件、技能卡片网格与右侧详情面板。
6. 热门工具组合、社区精选、教程引导横幅。
7. 页脚品牌区、资源链接、社交图标与语言控件。

## 基准视口

- 桌面视觉校准宽度为 1448 CSS px，与仓库中现有 Skills 原型素材的原始宽度一致。
- 用户提供的长图以宽度等比缩放至 1448 px 后作为整页区域顺序与纵向节奏的参照；页面内容决定全页高度，不固定高度。
- 窄屏布局仅要求保持内容可读与交互可用，不纳入 1448 px 桌面 1:1 验收。

## 视觉实现策略

- 使用现有可访问的 HTML 内容与 CSS 布局，优先精确校准原型桌面视口的宽度、栏位、间距、字体、颜色、阴影、边框圆角和垂直节奏。
- 原型截图可作为比对依据或裁切其中独立插画/装饰素材；不得用整屏截图遮盖真实 DOM 内容。
- 避免新增依赖。小屏样式在维持内容可读与交互可用的前提下适配，不作为牺牲桌面原型精度的理由。

## 验收标准

- Skills 页面各主要区域顺序、占位比例及视觉细节与原型一致，1448 CSS px 桌面基准宽度下达到用户要求的 1:1 复刻目标；整页截图按同一宽度比例对照。
- 页面真实技能内容和现有交互仍由 HTML/JavaScript 正常提供，原型视觉不会遮挡或替代内容。
- 变更局限于 Skills 页面，不覆盖工作区中已有的其他未提交修改。\n
