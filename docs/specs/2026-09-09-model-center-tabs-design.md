# 模型中心双 Tab 设计

## 目标

新增一个独立的模型中心页，将现有特色资源发现体验与完整模型目录放在同一页面中切换，同时保持原首页、资源目录、指南、分类和 Offer 详情路由不变。

## 页面结构

- 共享区：复用现有特色页面的导航、Hero、搜索和基础筛选，不放入 Tab 容器，两个视图都能使用。
- Tab 1「精选资源」：在共享区下面继续显示原有分类、热门资源、比较和资源详情入口。
- Tab 2「全部模型」：在共享区下面显示完整模型目录，保留搜索、厂家筛选、评分/厂家/模型分组、评分圆环、活动、状态、来源和详情入口。
- 默认打开 Tab 1；Tab 2 可通过按钮和 URL hash `#all-models` 直接进入。
- 新页面使用独立路径 `/models/center/`；原 `/`、`/models/`、`/guides/`、`/category/`、`/offers/` 不改变。

## 实现边界

新页面由现有静态 SEO 构建器生成。Tab 1 使用同一份 `offers.json` 的资源卡片和筛选数据，Tab 2 使用 `models.json` 的完整目录数据；两者共享本地化导航、统计和站内链接，不复制或删除旧页面文件。

## 交互与兼容

Tab 切换只隐藏或显示共享区下方的内容，不触发页面跳转；切换时同步 `aria-selected`、页面状态和 URL hash。浏览器打开 `/models/center/#all-models` 时直接显示 Tab 2。无 JavaScript 时共享区和两个内容区仍按顺序可见，保证静态内容可读。

## 验收标准

1. 新页面包含两个 Tab，默认 Tab 1，hash 可直接打开 Tab 2。
2. Tab 1 保留特色资源搜索/筛选/卡片入口，Tab 2 保留完整目录能力。
3. 原首页特色文案、原 `/models/` 页面和既有详情路由仍存在。
4. sitemap 收录新页面，构建产物和既有测试全部通过。
