# FreeLLM SEO 内容扩展与内链优化设计

日期：2026-09-09

## 目标

在不批量制造薄内容、不改变现有数据可信度的前提下，为 FreeLLM 增加有明确搜索意图的入口页，并让首页、分类页、指南页、模型目录互相形成清晰的内部链接网络。目标是提高 Google 发现和理解站点主题的机会，而不是承诺短期排名或流量。

## 当前基础

- 现有 Sitemap 约 49 个 URL。
- `data/offers.json` 是免费资源和官方来源的事实数据源。
- `data/models.json` 是模型目录和上下文窗口等参数的数据源。
- 已有 OpenAI API、Claude Code 指南和模型目录页面。
- AdSense 自动广告脚本已覆盖生成的页面。

## 方案

### 1. 新增主题入口页

新增 6 个可抓取的双语指南页，每页使用现有已核验数据，并提供独立的解释、筛选条件和官方链接：

- `/guides/free-openai-compatible-apis/`：免费或试用的 OpenAI 兼容 API。
- `/guides/free-ai-coding-tools/`：免费 AI 编程 IDE、编码计划和开发工具。
- `/guides/free-ai-search-apis/`：搜索、抓取、浏览器和 Agent 类免费入口。
- `/guides/open-weight-models/`：开放权重模型、下载入口和本地使用注意事项。
- `/guides/model-context-windows/`：按模型展示上下文窗口，并说明不同厂商口径。
- `/guides/china-free-ai-api/`：面向中国用户的地区、注册、额度和兼容性说明。

页面不只复制分类列表：每页包含主题说明、适用人群、限制条件、推荐入口、参数表和相关页面链接；没有满足条件的资源时明确显示“未核验”，不填充推测数据。

### 2. 改进内部链接

- 首页增加“热门主题入口”模块，链接到上述指南和现有 OpenAI、Claude Code 指南。
- 模型目录增加“按上下文窗口查看”和相关指南入口。
- 分类页和资源详情页增加相关指南链接。
- 所有新增页面加入 Sitemap，并使用 canonical、双语标题/描述、BreadcrumbList 或 CollectionPage 结构化数据。
- 保持现有语言切换行为和 AdSense 脚本。

### 3. 生成方式

继续使用 `scripts/build_seo_pages.py` 统一生成页面，不手工维护重复 HTML。主题页的配置、标题、说明和筛选规则集中在生成器中；资源和模型事实仍来自 JSON 数据源。

## 非目标

- 不自动向 GitHub、论坛或第三方网站发外链。
- 不为每个模型无差别生成低信息量详情页。
- 不使用未经官方来源核验的额度、价格或上下文窗口数据。
- 不保证 Google 立即收录、排名或 AdSense 立即产生收入。

## 验收标准

- 新增 6 个页面均返回 200，拥有唯一 title、description、canonical 和至少一个清晰的 H1。
- 新页面全部出现在 Sitemap，且从首页或已有页面可通过内部链接到达。
- 页面中展示的资源和模型均能追溯到现有 JSON 数据；无效筛选不输出空的虚假推荐。
- 中英文切换后，英文视图不显示中文正文。
- 新页面含 AdSense 脚本，但不硬编码不存在的广告位 ID。
- 现有 SEO、静态构建和 Sitemap 检查通过；与本次改动无关的既有测试失败单独记录。

## 发布与观察

完成生成和测试后部署到 `freellm.top`，再在 Search Console 对新增主题页逐步提交索引请求。观察 7—28 天的展示、查询词、收录状态和页面访问量，再决定是否增加下一批内容。
