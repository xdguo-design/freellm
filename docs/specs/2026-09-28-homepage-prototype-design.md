# FreeLLM 首页原型对照改造设计

## 目标

将生产首页调整为用户提供的浅蓝 AI 资源首页原型：深色左侧导航、顶部全站搜索、左文右图 Hero、横向统计与动态卡片、分类入口、资源卡片和学生福利横幅。首页继续展示 FreeLLM 已核验的真实数据与现有导航，不添加虚构的账号能力、产品数据或用户指标。

## 结构与实现

- 入口仍为 `design/free-china-ai-index.html`，生产根路径保持当前 Vercel rewrite。
- 复用 `js/reference-shell.js` 注入的导航、顶部搜索、统计与首页辅助区域；只调整首页的区块顺序与首页文案，不改其他页面的区块顺序。
- 将 `.today-latest` 作为五列统计入口，动态卡片紧随统计区，分类筛选与首页真实资源列表按原型顺序展示；资源详情、搜索、分类、地区、免费方式和排序仍使用原有 DOM hooks 与事件逻辑。
- 用新增的宽屏 3D 蓝白地球插画替换首页 Hero 背景素材。图片只承担装饰，标题和资源信息仍是可访问的 HTML 文本。
- 资源卡和学生福利入口链接到现有资源、筛选和官方页面；保留声明数据核验状态的原文，不伪造热度、认证或登录状态。

## 视觉与响应式

- 首页沿用参考图的海军蓝侧栏、雾白与浅蓝画布、蓝色主按钮、轻边框和柔和阴影。
- 桌面统计与动态区域最多五列，主资源卡为三列；宽度下降时改为两列和单列，侧栏在小屏改为顶部导航。
- 为 Hero 插画设置独立加载路径与底色回退；保留键盘焦点、语义标题、分类按钮状态和 reduced-motion 规则。

## 范围与验证

- 仅调整首页的 HTML 接入、`js/reference-shell.js` 首页组装、`css/reference-ui.css` 首页样式，以及新增 Hero 图片和本设计/计划文档。
- 不改 offers schema、排序逻辑、模型/工具/Skills 页面或部署配置。
- 在本地首页以桌面和窄屏视口查看实际渲染，检查搜索与分类仍指向原有功能；不新增或运行测试套件。
