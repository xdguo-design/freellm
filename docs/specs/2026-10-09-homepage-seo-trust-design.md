# 首页 SEO 与信任信息补强设计

## 目标

在保持 FreeLLM 为免费 AI 资源目录的前提下，让中文首页更清楚地说明目录收录什么、如何核验和信息有哪些边界，并让中英文首页的结构化数据准确描述资源集合。页面说明必须直接存在于静态 HTML，搜索引擎不执行 JavaScript 也能读取。

## 现状

- 中文首页 `design/free-china-ai-index.html` 已有标题、描述、canonical、`zh-CN` / `en` / `x-default` hreflang、`WebSite` 与 `CollectionPage` JSON-LD、每日变化、分类、指南链接和 FAQ。它的 JSON-LD 还把首页标为 `AboutPage`，与首页实际用途不符。
- 英文首页 `en/index.html` 已有独立标题与描述、canonical、双语 hreflang、目录说明、核验步骤、信息边界和目录入口；目前没有 JSON-LD。
- 首页已链接到隐私政策、使用条款、关于页面；关于页和社区页已提供核验说明与反馈入口。
- 网站已有静态指南、分类、模型、提供商和资源详情页，因此本次不创建重复的博客内容区。

## 方案

### 中文首页

在首页首屏介绍和目录内容之间增加一段短的静态说明，集中讲清：

1. 收录范围：免费模型与 API、开发工具、试用和开源权重等资源。
2. 核验方式：优先核对官方来源，注明地区、账号、额度和有效期等条件，并展示最近核验信息。
3. 使用边界：资源条件可能变化；目录记录和来源检查不等同于服务保证或每个模型都经过实际调用测试。

说明中使用普通站内链接指向指南、关于/核验方法、社区反馈和条款页面。避免与已有 FAQ、每日扫描卡片及分类链接重复，避免关键词堆砌。

中文首页主 JSON-LD 图谱保留 `WebSite` 与 `CollectionPage`，移除描述首页的 `AboutPage` 节点。保留现有动态 `ItemList` 与 `FAQPage` 图谱。不要把目录标记成聊天应用，也不添加未验证的评分、评论或免费次数承诺。

### 英文首页

保留现有的目录介绍、核验步骤和限制说明，不重复添加相同段落。在 `en/index.html` 增加与实际用途一致的 `WebSite` 和 `CollectionPage` JSON-LD，使中英文首页都能被描述为资源目录；保留各自 canonical URL 和现有 hreflang。

## 数据流与边界

- 中文主页的唯一编辑源和生成目标是 `design/free-china-ai-index.html`；`scripts/build_static.py` 会更新该页面中的资源计数、扫描数据和静态资源指纹。Vercel 将 `/` 重写到该静态文件。
- 英文首页是独立静态文件 `en/index.html`，不由中文首页生成器覆盖。
- 不修改现有数据模型、资源内容、路由、菜单、条款正文或扫描行为。
- 隐私、条款、About、社区、指南和 sitemap 入口沿用现状。

## 非目标

- 新建 `/blog/` 或引入 CMS、文章发布工作流。
- 开发聊天、游客试用、API Key 代理或 Prompt 模板功能。
- 新增社群渠道、状态页、站长平台账户或外链建设流程。
- 声称 `.top` 后缀直接导致排名降低，或承诺结构化数据必然带来富媒体摘要。

## 验收标准

- 构建生成后的 `/` 静态 HTML 包含简洁的目录范围、核验方式和信息边界说明，且通过普通文本可读。
- `/` 主 JSON-LD 图谱将首页描述为 `WebSite` 和 `CollectionPage`，不再把首页标记为 `AboutPage`；动态 `ItemList` 与 `FAQPage` 图谱仍保留。
- `/en/` 保留现有静态说明，并新增对应的 `WebSite` 与 `CollectionPage` JSON-LD；canonical 和 hreflang 保持指向当前双语 URL。
- 新说明的站内链接使用现有指南、关于/核验、社区或条款页面，不产生死链或重复菜单。
- 不引入虚构的免费使用承诺、模型实测结论、用户评分、评论或流量效果保证。

## 实施后验证

- 运行现有首页生成器检查模式，确认 `design/free-china-ai-index.html` 与生成首页一致。
- 检查中英文首页的 JSON-LD、canonical、hreflang 及新增内链，并确认新增说明位于静态 HTML 中。
- 查看页面布局，确认新增内容不会挤压首屏搜索和主要分类入口。
