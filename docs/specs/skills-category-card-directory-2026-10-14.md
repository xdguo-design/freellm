# FreeLLM Skills 分类卡片与独立详情页（2026-10-14）

## 数据范围
- 唯一来源：`data/skills.json` 的 98 条 Skill；按 `id` 保证唯一，保留原 `githubUrl`、原始描述、兼容客户端与核验日期。
- 分类：保持数据的 12 个 `category` 值，界面统一中文分类名；不同 Skill 不合并同名但不同来源的 ID。
- 目录：`/skills/catalog/` 总清单，按类分组；一个 Skill 一张卡片，包含英文原名、中文用途、适用场景、来源与详情页。
- 详情：`/skills/{id}/` 独立静态页面，使用结构化卡片呈现用途、场景、输入、工作流程、交付物、示例、边界与官方来源。
- 现有 `/skills/`：保持原实测信息、筛选器与对话框，增加“独立说明”入口和分类总清单入口。

## 信息可信度
- “已核验”只表示原目录状态，不表示 Skill 原代码已跑通。
- `data/evaluations/skills-latest.json` 是任务级模型检查（79 个 Skill），不等于原 Skill CLI/脚本端到端。
- 尚未实测的 Skill 明确显示“暂无本轮任务级实测”，不补造体验、支持程度和性能。
- 原仓库链接作为使用前的事实核对入口，安装命令不自动执行。

## 质量门槛
1. 目录卡片数量等于源数据数量、每个 ID 唯一且 12 个分类总数等于 98。
2. 每个详情页具有独立 title、canonical、meta description、导航返回路径及来源链接。
3. 分类、中文文案、输入输出、流程和风险必须符合 Skill 实际用途；保留英文原始范围作核对。
4. 静态 HTML 的动态文字做转义；仅允许 https 来源 URL，禁止插入任意 HTML。
5. PC 三列、平板两列、手机单列；支持键盘焦点、可读对比度和搜索无结果状态。
6. 先落 dev，确认构建与站内链接，再由项目发布流程决定是否合并 main。
