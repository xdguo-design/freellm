# FreeLLM 全站视觉与页面一致性审查 — 2026-09-21

## 范围

本轮以 `dev` 为发布基线，对仓库中的 HTML 页面按“正式站点页面 / 非发布审查材料”分组。

- HTML 总数：624
- 正式站点页面：587
- 快照、原型、营销稿、测试产物等非正式页面：37
- 正式页面家族：
  - 工具详情页：291
  - 模型相关页：194
  - Offer：48
  - Provider：27（1 个目录页 + 26 个厂家详情页）
  - 指南：9
  - 分类：7
  - Skills：2
  - 首页、Tools 首页、日志、About、Privacy、Terms、Links、Favorites、Submit：各 1

大量页面由同一生成器和同一视觉层生成，因此本轮采用“共享视觉层全量覆盖 + 各页面家族代表页检查 + 生成器回归测试”的方式，而不是对数百个同模板页面逐页手改。

## 已确认问题

### P0 / 数据与发布一致性

1. Tools 首页显示 295 个工具，但实际只有 291 个唯一工具页面。
   - 原因：`tools/js/tools.js` 中 `jwt`、`bmi`、`screen-record`、`pomodoro` 四个 ID 各重复一次。
   - 处理：删除重复注册项，真实口径统一为 291；构建脚本新增重复 ID 失败保护。

2. “厂家目录”数字与实际可浏览 Provider 页面不一致。
   - 原口径：`provider-catalog.json` 的 30 条来源记录。
   - 实际生成：26 个厂家详情页。
   - 处理：用户可见的“厂家目录”改为 26，与实际目录一致；保留“当前数据 Provider ID”作为另一独立口径。

3. 线上页面与 `dev` 源码存在版本漂移迹象。
   - 用户截图中的 Skills 标题仍为旧版，而 `dev` 已是“这些 Skill，能跑的真跑；跑不了的明确写阻塞”。
   - 线上 Models / Tools 也出现与 `dev` 生成内容不一致的表现。
   - 本项必须在合并 `dev` 后做线上二次核验；若仍不一致，应继续查 Vercel 项目绑定分支、部署产物或缓存，而不是继续改页面源码。

### P1 / 全站视觉层

1. 长中文 H1 尺寸偏大，Skills 首屏出现不自然折行。
2. 内容最大宽度过大，桌面端信息密度失衡。
3. Skills / Tools / Models 横向分类标签在窄屏可能截掉最后一项。
4. 表格容器使用隐藏溢出时可能静默裁掉列。
5. 卡片使用过多粉/蓝/绿渐变，信息层级被装饰抢走。
6. 页头、共享导航、页面内主题按钮存在重复视觉层级。
7. Skills 工具条在中小宽度下搜索、状态、计数容易挤压。
8. Dialog / Skill 原文 / code 长内容缺少统一的视口高度与滚动边界。

### P1 / 可访问性与交互

1. 缺少全站统一“跳到主要内容”入口。
2. 深浅主题入口分散在页面内部，生成页之间位置不一致。
3. 新窗口外链需要统一补 `noopener`。
4. 需要保留 `:focus-visible` 和 `prefers-reduced-motion`，并让新增控件继承同一规则。

## 本轮实现

### 共享视觉系统

修改 `css/freellm-pastel-ui.css`：

- 正式内容宽度统一为 1220px，正文阅读宽度约 780px。
- H1 统一为更克制的响应式字号与行高，并开启平衡换行。
- Skills / Tools / Skill Lab Hero 使用稳定的两栏信息结构，移动端回落单栏。
- Skills 3 / 2 / 1 列响应式卡片布局。
- 减少每张卡片的随机渐变，改为统一白色信息面 + 小型强调线。
- Skills / Tools / Model tabs 改为真正可横向滚动，不再裁掉尾部项。
- 表格统一 `overflow-x:auto`，不隐藏列。
- Dialog 限制最大视口高度并内部滚动。
- 新增 1100 / 700 / 480 三档适配。
- 保留首页“提交资源/本地时间”和 Tools “GitHub”这类页面特有功能，不因统一导航而隐藏。

### 全站交互增强

修改 `js/freellm-sync.js`：

- 统一在站点导航里提供深浅模式开关。
- 自动添加“跳到主要内容”链接。
- 为主内容建立稳定锚点。
- 对所有 `target="_blank"` 链接补 `noopener`。
- 兼容静态预渲染页面和运行时注入页面。

### 数据一致性保护

- Tools 注册表修正为 291 个唯一工具。
- Tools 首页静态总数同步为 291。
- `build_tools_index.py` 遇到重复工具 ID 直接失败。
- `build_tool_pages.py` 不再静默去重；重复 ID 直接失败。
- 模型概览 / About 的厂家目录统一为实际生成的 26 家。

## 发布后必须复核

合并到 `dev` 并触发自动发布后，至少核对：

1. `/skills/`：新 Hero、新真实验收 Banner、标签横向滚动、291/26 以外不相关数字不受影响。
2. `/models/`：厂家目录为 26，模型/Offer/Provider ID 各自口径仍独立。
3. `/tools/`：总数 291；搜索、分类、GitHub 按钮可用。
4. 首页：提交资源、本地时间、筛选和目录交互仍可用。
5. 任意 Offer / Provider / Model 详情：表格窄屏可横向滚动。
6. About / Privacy / Terms / Links：正文宽度、标题层级和深色模式一致。
7. 手机宽度：导航可达、正文无横向整页溢出、Hero 单栏、卡片单列。
8. 线上内容必须与 `dev` 最新提交一致；若仍显示旧 Skills / Models，则转入部署链路排查。
