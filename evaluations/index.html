→ 以下是一个实现 parse_duration 函数的 Python 代码：
```python
import re

def parse_duration(text):
    # 定义正则表达式匹配时长字符串的模式
    pattern = r'(\d+h)?(\d+m)?(\d+s)?$'

    # 将时长字符串转换为整数列表
    matches = re.match(pattern, text).groups()

    # 将每个整数转换为秒数
    seconds = [int(match) * 3600 if match else 0 for match in matches]

    # 将秒数相加返回结果
    return sum(seconds)
```
