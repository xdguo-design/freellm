# Free AI Index · Brand Spec

Date: 2026-09-06

## Product positioning

Free AI and limited-time-free AI discovery, with Chinese providers as the primary source market. The interface should lead with “free”, “trial”, “downloadable” and “cheap”, not with country of origin.

## Direction

Swiss index / high information density / neutral evidence-first tooling.

## Design tokens

- Ink: `#101113`
- Paper: `#F5F7F8`
- Blue: `#1744E8`
- Yellow: `#FFD51F`
- Free green: `#B8F1CC`
- Borders: `#D7DCE1`
- Display: Bricolage Grotesque fallback stack
- Body: DM Sans fallback stack
- Metadata: IBM Plex Mono fallback stack

## Asset status

The prototype uses honest two-letter/short-text provider marks so the index layout can be reviewed without inventing brand artwork. Before production, replace each mark with the verified official logo asset for the provider or product, using the official source links stored in the data record. No generated or hand-drawn brand logos should be used.

## Content rules

- Never call a paid first-month promotion “free”.
- Never call open weights “free inference”.
- Never claim a free API quota without a current official source.
- Show renewal price beside the promotional price.
- Show source, last checked date, validity, and account-region requirement on every offer.
